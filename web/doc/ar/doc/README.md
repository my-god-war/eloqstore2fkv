# eloqstore2fkv

مستودع التحقق من الترحيل والتوافق من eloqstore إلى fkv.

يظل مستودع fkv الرئيسي عبارة عن صدأ خالص ويتم بناؤه بشكل مستقل؛ يحتفظ هذا المستودع بأوراكل التنفيذ المرجعي لـ C++، وقاعدة البايت ثنائية الاتجاه،
ترحيل دفاتر الأستاذ وسجلات التدقيق التاريخية والتحقق من CI.

## محتوى

- أوراكل C++: ربط طبقة تنسيق eloqstore وإنشاء صفحة/فهرس/تجاوز/بيان/
  ضغط الجسم.
- مجموعة ثنائية الاتجاه: كتابة C++ → قراءة الصدأ، كتابة الصدأ → قراءة C++.
- `fkv_compat`: اختبار التوافق من جانب الصدأ، بالاعتماد على صندوق التنسيق الخاص بمستودع fkv.
- `fkv_ledger`: قم بمسح eloqstore، وتسجيل دفتر الأستاذ الخاص بالترحيل، وإنشاء النصوص والتحقق منها.
- مقارنة الأداء: مقارنة خطوط الأساس fkv وC++ تحت نفس عبء العمل.
