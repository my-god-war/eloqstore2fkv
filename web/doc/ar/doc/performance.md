# أداء

قم بتنزيل `perf-latest` من `fkv_bench` من مستودع fkv وقم بتشغيل نفس حمل العمل على جهاز ثابت.
وقارن الإنتاجية وزمن الوصول وذروة RSS بخط الأساس لـ C++.

مصدر المعلمة متوافق مع fkv:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

يتم تشغيل خط الأساس لـ C++ بواسطة بيئة Oracle `simple_bench` ثم يتم إخراجه وفقًا لنفس المخطط ونشره على
`perf-baseline` أصل الإصدار. تتم إعادة كتابة نتائج المقارنة إلى مستند المستودع، ويقوم الموقع بعرض Markdown مباشرةً.
لا يتم الاحتفاظ بطبقة بيانات JSON.
