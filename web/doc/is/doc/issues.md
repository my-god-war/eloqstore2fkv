# Farið yfir skrár

`issue/` er endurskoðunarborðið meðan á flutningi stendur:

- `new/`: Færsla fyrir nýjar athugasemdir.
- `todo/`: Samþykkt, bíður þróun.
- `done/`: Þróað og hefur prófunarsönnunargögn, bíður endurskoðunar.
- `reviewed/`: Skjalasafn skoðað.
- `reject/`: Ef það er ekki samþykkt, vinsamlegast tilgreinið ástæðurnar.

Sjá `issue/new.md`, `issue/run.md`, `issue/review.md` fyrir ferlið.

Í umsögninni er lögð áhersla á hegðunarmun, sniðsamhæfni, frammistöðu og kóðauppbyggingu á milli fkv og C++ útfærslur. Ein skoðun pr
skrár til að forðast magnflutninga.
