# 2026-11-06. Գլխավոր էջի կատարողականի աղյուսակ, ցուցիչի ընդլայնում և Էջեր

Այսօրվա թարմացումը կենտրոնանում է կատարողականի ակնարկների և կայքի գործարկման վրա:

## Գլխավոր էջի կատարողականի համեմատություն

- Գլխավոր էջը փոխվում է աշխատանքի առաջնահերթության, իսկ C++/Rust համեմատության աղյուսակը ուղղակիորեն ցուցադրվում է առաջին էկրանին:
- Ավելացվել են ցուցիչների երեք նոր հավաքածուներ՝ տրամաբանական թողունակություն, P99.9 պոչի հետաձգում և տարածական ուժեղացում:
- Ավելացվեցին Rust-ի գործարկման մանրամասները. սկան, ամբողջական սկանավորում, գրի ուժեղացում, գրելու համակարգային զանգերի քանակ և տվյալների համաժամացում յուրաքանչյուր խմբաքանակի համար:
- Հստակ նշեք `write-read` որպես խառը տրամաչափ և հղում կատարողական փաստաթղթերին:

Ներկայիս նույն մեքենայի ելակետային գիծը.

| ցուցանիշը | C++ | Rust | Rust / C++ |

| Put | 16,866 kv/s | 21,377 kv/s | 1.27x |

## Գնահատման ցուցանիշներ

Անդրադառնալով RocksDB, LevelDB, YCSB, WiredTiger և այլ հենանիշերի ընդհանուր արդյունքին, ես ավելացրեցի.

- Տրամաբանական կարդալու և գրելու թողունակություն MiB/s;
- P99.9 պոչի հետաձգում;
- Տիեզերքի ուժեղացում, գրավոր ուժեղացում;
- Գրելու համակարգային զանգերի և տվյալների համաժամացման քանակը յուրաքանչյուր խմբաքանակում;
- Սկան / Ամբողջական սկան թողունակություն;
- CPU-ն, էջի անսարքությունները, համատեքստի անջատիչները և գործընթացի IO-ն շարունակում են հավաքվել ռեսուրսի կողային սարքի կողմից:

Միաժամանակ թոշակի անցավ`gxhash_4096B_gib_s`: Այն 4 KiB մեկ բլոկի հեշ միկրոհենանիշ է, որը KV շարժիչի ուղու վրա չէ և չունի C++ նմանակ:

## Ճշգրտություն և ինժեներական ուղղումներ

- Ուղղեք `--rng cpp` read/scan-ի բանալիների տարածությունը. կարդալու հայտնաբերումն այլևս չի բազմապատկվում `key_interval`-ով, որպեսզի չգրված ստեղների մեջ չընկնի ընթերցումների 75%-ը:
- Միևնույն բովանդակությամբ մանիֆեստների macOS `openrsync` սխալ գնահատման հետևանքով շտկվել են սպասման ռեժիմում կրկնվող փորձերը:
- Շտկվել է ապարատային դարպասի խնդիր, որտեղ QEMU վիրտուալ սկավառակները սխալ են գնահատվել որպես տեղական SSD:

## Կայքեր և հրատարակում

- Կայքի երթուղին աջակցում է `/eloqstore2fkv/` ենթուղիներին:
- Փոխարենը փաստաթուղթը կարդացվում է `raw.githubusercontent.com`-ից, և jsDelivr ճանապարհին `web/` բացակայելու պատճառով առաջացած 404-ը ուղղվում է:
- Բլոգի նավիգացիան և `bun run tran` բազմալեզու թարգմանությունը ինտեգրված են. այս հոդվածը չինական աղբյուրից ավտոմատ կերպով թարգմանվում է այլ լեզուներով:
