# eloqstore2fkv

Միգրացիայի և համատեղելիության ստուգման պահեստ eloqstore-ից մինչև fkv:

Հիմնական fkv պահեստը մնում է մաքուր Rust և կառուցված է ինքնուրույն; այս պահոցը պահպանում է C++ հղումների իրականացման օրակուլը, երկկողմանի բայթային կորպուսը,
Տեղափոխեք մատյանները, պատմական աուդիտի գրառումները և ստուգեք CI:

## բովանդակությունը

- C++ oracle. կապել eloqstore ձևաչափի շերտը և ստեղծել էջ/ինդեքս/հորդառատ/մանիֆեստ/
  սեղմել կորպուսը:
- Երկկողմանի կորպուս. C++ գրել → Rust կարդալ, Rust գրել → C++ կարդալ:
- `fkv_compat`՝ ժանգոտող կողմի համատեղելիության թեստ՝ հենվելով fkv պահեստի ձևաչափի վրա:
- `fkv_ledger`. սկանավորեք eloqstore-ը, գրանցեք միգրացիայի մատյան, ստեղծեք և ստուգեք կորպուսը:
- Արդյունավետության համեմատություն. Համեմատեք fkv և C++ հիմնական գծերը նույն ծանրաբեռնվածության ներքո:
