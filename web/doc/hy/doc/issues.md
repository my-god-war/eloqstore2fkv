# Վերանայեք գրառումները

`issue/`-ը միգրացիայի ժամանակ վերանայման խորհուրդն է.

- `new/`. Մուտք նոր մեկնաբանությունների համար:
- `todo/`: Ընդունված է, սպասվում է մշակման:
- `done/`. Մշակված է և ունի թեստային ապացույցներ, որոնք սպասում են վերանայմանը:
- `reviewed/`. արխիվը վերանայվել է:
- `reject/`. Եթե չի ընդունվել, խնդրում ենք նշել պատճառները:

Գործընթացի համար տես `issue/new.md`, `issue/run.md`, `issue/review.md`:

Վերանայումը կենտրոնանում է վարքագծային տարբերությունների, ձևաչափի համատեղելիության, կատարողականի և կոդերի կառուցվածքի վրա fkv և C++ իրականացումների միջև: Մեկ կարծիք մեկ
ֆայլեր՝ զանգվածային շարժումներից խուսափելու համար:
