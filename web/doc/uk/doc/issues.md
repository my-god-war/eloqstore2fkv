# Перегляньте записи

`issue/` - це панель перегляду під час міграції:

- `new/`: Запис для нових коментарів.
- `todo/`: прийнято, очікує розробки.
- `done/`: Розроблено та має докази тестування, очікує на розгляд.
- `reviewed/`: Архів переглянуто.
- `reject/`: Якщо не прийнято, вкажіть причини.

Див. процес `issue/new.md`, `issue/run.md`, `issue/review.md`.

Огляд зосереджується на поведінкових відмінностях, сумісності форматів, продуктивності та структурі коду між реалізаціями fkv і C++. Одна думка на
файлів, щоб уникнути масових переміщень.
