# eloqstore2fkv

Сховище міграції та перевірки сумісності з eloqstore на fkv.

Основне сховище fkv залишається чистим Rust і створюється незалежно; це сховище зберігає оракул еталонної реалізації C++, двонаправлений байтовий корпус,
Перенесіть облікові книги, історичні записи аудиту та перевірте КІ.

## вміст

- C++ oracle: зв’яжіть рівень формату eloqstore і згенеруйте page/index/overflow/manifest/
  стиснути корпус.
- Двонаправлений корпус: C++ запис → Rust читання, Rust запис → C++ читання.
- `fkv_compat`: Тест на сумісність із стороною Rust, покладаючись на ящик формату зі складу fkv.
- `fkv_ledger`: Сканування eloqstore, запис міграційної книги, створення та перевірка корпусу.
- Порівняння продуктивності: порівняйте базові показники fkv і C++ за однакового робочого навантаження.
