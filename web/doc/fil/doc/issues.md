# Suriin ang mga talaan

Ang `issue/` ay ang review board sa panahon ng paglipat:

- `new/`: Entry para sa mga bagong komento.
- `todo/`: Pinagtibay, nakabinbing pag-unlad.
- `done/`: Binuo at may pansubok na ebidensya, nakabinbing pagsusuri.
- `reviewed/`: Nasuri ang archive.
- `reject/`: Kung hindi pinagtibay, pakisabi ang mga dahilan.

Tingnan ang `issue/new.md`, `issue/run.md`, `issue/review.md` para sa proseso.

Nakatuon ang pagsusuri sa mga pagkakaiba sa pag-uugali, compatibility ng format, performance, at istruktura ng code sa pagitan ng mga pagpapatupad ng fkv at C++. Isang opinyon sa bawat
mga file upang maiwasan ang maramihang paglipat.
