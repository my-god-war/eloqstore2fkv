# レビュー記録

`issue/` は移行中のレビュー委員会です。

- `new/`: 新しいコメントのエントリ。
- `todo/`: 採用されましたが、開発は保留中です。
- `done/`: 開発され、テスト証拠があり、審査待ちです。
- `reviewed/`: アーカイブが確認されました。
- `reject/`: 採用されない場合は、その理由を記載してください。

プロセスについては、`issue/new.md`、`issue/run.md`、`issue/review.md`を参照してください。

このレビューは、fkv 実装と C++ 実装の間の動作の違い、形式の互換性、パフォーマンス、およびコード構造に焦点を当てています。 1件につき1つの意見
ファイルの一括移動を避けるため。
