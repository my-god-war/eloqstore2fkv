# Review cathetan

`issue/` minangka papan review nalika migrasi:

- `new/`: Entri kanggo komentar anyar.
- `todo/`: Diadopsi, pembangunan sing ditundha.
- `done/`: Dikembangake lan duwe bukti tes, nunggu review.
- `reviewed/`: Arsip dideleng.
- `reject/`: Yen ora diadopsi, sebutno alasane.

Deleng `issue/new.md`, `issue/run.md`, `issue/review.md` kanggo proses kasebut.

Tinjauan kasebut fokus ing beda prilaku, kompatibilitas format, kinerja, lan struktur kode antarane implementasi fkv lan C++. Siji pendapat saben
file supaya gerakane akeh.
