# eloqstore2fkv

Миграция и проверка совместимости склада с eloqstore на fkv.

Основной репозиторий fkv остается чистым Rust и создается независимо; в этом репозитории хранится эталонная реализация C++ oracle, двунаправленный корпус байтов,
Переносите реестры, исторические записи аудита и проверяйте CI.

## содержание

- C++ oracle: связать слой формата eloqstore и создать страницу/индекс/переполнение/манифест/
  сжимать корпус.
- Двунаправленный корпус: запись C++ → чтение Rust, запись Rust → чтение C++.
- `fkv_compat`: тест совместимости со стороны Rust, основанный на контейнере формата хранилища fkv.
- `fkv_ledger`: сканирование eloqstore, запись книги миграции, создание и проверка корпуса.
- Сравнение производительности: сравните базовые показатели fkv и C++ при одной и той же рабочей нагрузке.
