# Просмотр записей

`issue/` — это доска обзора во время миграции:

- `new/`: запись для новых комментариев.
- `todo/`: принято, ожидает разработки.
- `done/`: разработано и имеет доказательства испытаний, ожидает рассмотрения.
- `reviewed/`: Архив проверен.
- `reject/`: Если решение не принято, укажите причины.

См. `issue/new.md`, `issue/run.md`, `issue/review.md` для получения информации о процессе.

В обзоре основное внимание уделяется различиям в поведении, совместимости форматов, производительности и структуре кода между реализациями fkv и C++. Одно мнение на
файлы, чтобы избежать массовых перемещений.
