# পারফরম্যান্স

fkv সংগ্রহস্থল থেকে `perf-latest` এর `fkv_bench` ডাউনলোড করুন এবং একটি নির্দিষ্ট মেশিনে একই কাজের চাপ চালান৷
এবং একটি C++ বেসলাইনের সাথে থ্রুপুট, লেটেন্সি কোয়ান্টাইল এবং পিক RSS তুলনা করুন।

পরামিতি উৎস fkv এর সাথে সামঞ্জস্যপূর্ণ:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

C++ বেসলাইন ওরাকল এনভায়রনমেন্ট `simple_bench` দ্বারা চালিত হয় এবং তারপরে একই স্কিমা অনুসারে আউটপুট এবং প্রকাশিত হয়
`perf-baseline` রিলিজ সম্পদ। তুলনা ফলাফল গুদাম নথিতে ফিরে লেখা হয়, এবং সাইটটি সরাসরি মার্কডাউন রেন্ডার করে।
কোন JSON ডেটা স্তর বজায় রাখা হয় না।

48.2 ms), একক বেসলাইন ব্যাপকভাবে ওঠানামা করে, অনুগ্রহ করে বিস্তারিত জানার জন্য অভ্যন্তরীণ পারফ রিপোর্টটি দেখুন।

**দ্রষ্টব্য**: C++ এর `write-read` মানে লেখার থ্রেড এবং রিডিং থ্রেড একই সময়ে চলে এবং বর্তমানে মরিচা ধরেছে
"সম্পূর্ণ লেখা, আবার খুলুন, এবং আবার পড়ুন", পড়ার পর্যায়ে কোন লেখার প্রতিযোগিতা নেই। তাই `write-read` এর গুণক হিসাবে গণ্য করা যাবে না
বিশুদ্ধ পাঠ/বিশুদ্ধ লেখার উপসংহার; কঠোর তুলনা `scripts/perf_local.sh --symmetric` দেখতে হবে
ফলাফলের দুটি জোড়া আউটপুট: শুধুমাত্র লিখুন এবং শুধুমাত্র পঠন। একক ভাগ করা রানার নম্বরগুলি শুধুমাত্র রিগ্রেশনের জন্য ব্যবহার করা হয়
প্রবণতা, প্রকাশগুলি `--runs` এর মধ্যমা ব্যবহার করে বিচার করা হয়৷
