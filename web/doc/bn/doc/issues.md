# রেকর্ড পর্যালোচনা

`issue/` হল মাইগ্রেশনের সময় পর্যালোচনা বোর্ড:

- `new/`: নতুন মন্তব্যের জন্য প্রবেশ।
- `todo/`: গৃহীত, মুলতুবি বিকাশ।
- `done/`: বিকশিত এবং পরীক্ষার প্রমাণ রয়েছে, পর্যালোচনা মুলতুবি।
- `reviewed/`: সংরক্ষণাগার পর্যালোচনা করা হয়েছে৷
- `reject/`: যদি গৃহীত না হয়, অনুগ্রহ করে কারণগুলি বলুন৷

প্রক্রিয়াটির জন্য `issue/new.md`, `issue/run.md`, `issue/review.md` দেখুন৷

পর্যালোচনাটি fkv এবং C++ বাস্তবায়নের মধ্যে আচরণগত পার্থক্য, বিন্যাস সামঞ্জস্য, কর্মক্ষমতা এবং কোড কাঠামোর উপর দৃষ্টি নিবদ্ধ করে। প্রতি এক মতামত
বাল্ক চালনা এড়াতে ফাইল.
