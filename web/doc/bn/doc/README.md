# eloqstore2fkv

eloqstore থেকে fkv-এ মাইগ্রেশন এবং সামঞ্জস্য যাচাইয়ের গুদাম।

প্রধান fkv সংগ্রহস্থল বিশুদ্ধ মরিচা থেকে যায় এবং স্বাধীনভাবে নির্মিত হয়; এই সংগ্রহস্থলটি C++ রেফারেন্স বাস্তবায়ন ওরাকল, দ্বিমুখী বাইট কর্পাস,
মাইগ্রেট লেজার, ঐতিহাসিক অডিট রেকর্ড এবং CI যাচাই করুন।

## বিষয়বস্তু

- C++ ওরাকল: এলোকস্টোর ফরম্যাট লেয়ার লিঙ্ক করুন এবং পেজ/ইনডেক্স/ওভারফ্লো/মেনিফেস্ট/ তৈরি করুন
  কম্প্রেস কর্পাস।
- দ্বিমুখী কর্পাস: C++ লিখুন → মরিচা পড়ুন, মরিচা লিখুন → C++ পড়ুন।
- `fkv_compat`: মরিচা-সাইড সামঞ্জস্য পরীক্ষা, fkv গুদামের ফর্ম্যাট ক্রেটের উপর নির্ভর করে।
- `fkv_ledger`: eloqstore স্ক্যান করুন, মাইগ্রেশন লেজার রেকর্ড করুন, কর্পাস তৈরি এবং যাচাই করুন।
- কর্মক্ষমতা তুলনা: একই কাজের চাপের অধীনে fkv এবং C++ বেসলাইন তুলনা করুন।
