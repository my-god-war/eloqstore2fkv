# 2026-11-06: Πίνακας απόδοσης αρχικής σελίδας, επέκταση δείκτη και Σελίδες

Η σημερινή ενημέρωση επικεντρώνεται σε αξιολογήσεις απόδοσης και εκκινήσεις ιστοτόπων.

## Σύγκριση απόδοσης αρχικής σελίδας

- Η αρχική σελίδα αλλάζει σε προτεραιότητα απόδοσης και ο πίνακας σύγκρισης C++/Rust εμφανίζεται απευθείας στην πρώτη οθόνη.
- Τρία νέα σύνολα δεικτών προστίθενται: λογικό εύρος ζώνης, καθυστέρηση ουράς P99.9 και χωρική ενίσχυση.
- Προστέθηκαν λεπτομέρειες λειτουργίας Rust: Σάρωση, Πλήρης σάρωση, ενίσχυση εγγραφής, αριθμός κλήσεων συστήματος εγγραφής και συγχρονισμός δεδομένων ανά παρτίδα.
- Επισημάνετε ρητά το `write-read` ως μικτό διαμέτρημα και συνδέστε την τεκμηρίωση απόδοσης.

Τρέχουσα γραμμή βάσης ίδιας μηχανής:

| δείκτης | C++ | Rust | Rust / C++ |

| Put | 16,866 kv/s | 21,377 kv/s | 1.27x |

| Put P99.9 | 86.0 ms | 223.3 ms | 2.60x |
| Get P99.9 | 48.2 ms | 355.5 ms | 7.37x |
| Κορυφαίο RSS | 175.6 MiB | 145.5 MiB | 0.83x |
| Χρήση αποθήκευσης | 269.0 MiB | 101.4 MiB | 0.38x |

## Δείκτες αξιολόγησης

Αναφερόμενος στην κοινή έξοδο των RocksDB, LevelDB, YCSB, WiredTiger και άλλων σημείων αναφοράς, πρόσθεσα:

- Λογικό εύρος ζώνης ανάγνωσης και εγγραφής MiB/s.
- P99.9 καθυστέρηση ουράς;
- Ενίσχυση χώρου, ενίσχυση γραφής.
- Αριθμός κλήσεων συστήματος εγγραφής και συγχρονισμός δεδομένων σε κάθε παρτίδα.
- Παροχή σάρωσης / πλήρους σάρωσης.
- Η CPU, τα σφάλματα σελίδας, οι διακόπτες περιβάλλοντος και το IO διεργασίας συνεχίζουν να συλλέγονται από το sidecar του πόρου.

Συνταξιοδοτήθηκε ταυτόχρονα`gxhash_4096B_gib_s`. Είναι ένα microbenchmark κατακερματισμού ενός μπλοκ 4 KiB που δεν βρίσκεται στη διαδρομή του κινητήρα KV και δεν έχει αντίστοιχο C++.

## Διορθώσεις ορθότητας και μηχανικής

- Διορθώστε τον χώρο κλειδιού του `--rng cpp` ανάγνωσης/σάρωσης: η ανίχνευση ανάγνωσης δεν πολλαπλασιάζεται πλέον με `key_interval` για να αποφύγετε το 75% των αναγνώσεων να πέσει σε άγραφα κλειδιά.
- Διορθώθηκαν οι επαναλήψεις σε κατάσταση αναμονής που προκλήθηκαν από εσφαλμένη εκτίμηση του macOS `openrsync` μανιφέστων με το ίδιο περιεχόμενο.
- Διορθώθηκε ένα πρόβλημα πύλης υλικού όπου οι εικονικοί δίσκοι QEMU δεν εκτιμήθηκαν σωστά ως τοπικοί SSD.
