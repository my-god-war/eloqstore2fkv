# eloqstore2fkv

Αποθήκη μετεγκατάστασης και επαλήθευσης συμβατότητας από το eloqstore στο fkv.

Το κύριο αποθετήριο fkv παραμένει καθαρό Rust και είναι κατασκευασμένο ανεξάρτητα. αυτό το αποθετήριο διατηρεί το μαντείο υλοποίησης αναφοράς C++, αμφίδρομο σώμα byte,
Μεταφορά λογιστικών βιβλίων, ιστορικά αρχεία ελέγχου και επαλήθευση CI.

## περιεχόμενο

- C++ oracle: συνδέστε το επίπεδο μορφής eloqstore και δημιουργήστε σελίδα/ευρετήριο/υπερχείλιση/μανιφέστο/
  συμπίεση σώματος.
- Σώμα αμφίδρομης κατεύθυνσης: C++ write → Rust read, Rust write → C++ read.
- `fkv_compat`: Δοκιμή συμβατότητας από την πλευρά της σκουριάς, που βασίζεται στο κιβώτιο μορφοποίησης της αποθήκης fkv.
- `fkv_ledger`: Σαρώστε το eloqstore, καταγράψτε το καθολικό μετεγκατάστασης, δημιουργήστε και επαληθεύστε το σώμα.
- Σύγκριση απόδοσης: Συγκρίνετε τις βασικές γραμμές fkv και C++ με τον ίδιο φόρτο εργασίας.
