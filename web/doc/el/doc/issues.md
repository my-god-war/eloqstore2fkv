# Επανεξέταση αρχείων

Το `issue/` είναι ο πίνακας αξιολόγησης κατά τη μετεγκατάσταση:

- `new/`: Καταχώριση για νέα σχόλια.
- `todo/`: Εγκρίθηκε, εκκρεμεί ανάπτυξη.
- `done/`: Αναπτύχθηκε και διαθέτει αποδεικτικά στοιχεία δοκιμής, εκκρεμεί έλεγχος.
- `reviewed/`: Το αρχείο εξετάστηκε.
- `reject/`: Εάν δεν εγκριθεί, αναφέρετε τους λόγους.

Δείτε τα `issue/new.md`, `issue/run.md`, `issue/review.md` για τη διαδικασία.

Η ανασκόπηση επικεντρώνεται στις διαφορές συμπεριφοράς, τη συμβατότητα μορφής, την απόδοση και τη δομή κώδικα μεταξύ των υλοποιήσεων fkv και C++. Μία γνώμη ανά
αρχεία για την αποφυγή μαζικών μετακινήσεων.
