# Yozuvlarni ko'rib chiqish

`issue/` - ko'chirish paytida ko'rib chiqish kengashi:

- `new/`: Yangi sharhlar uchun kirish.
- `todo/`: Qabul qilingan, ishlab chiqilishi kutilmoqda.
- `done/`: Ko'rib chiqilishi kutilayotgan sinov dalillari ishlab chiqilgan va mavjud.
- `reviewed/`: Arxiv ko'rib chiqildi.
- `reject/`: Agar qabul qilinmasa, sabablarini ko'rsating.

Jarayon uchun `issue/new.md`, `issue/run.md`, `issue/review.md` ga qarang.

Sharh fkv va C++ ilovalari o'rtasidagi xatti-harakatlardagi farqlar, format mosligi, unumdorligi va kod tuzilishiga qaratilgan. Bitta fikr
fayllarni ommaviy ko'chirishni oldini olish uchun.
