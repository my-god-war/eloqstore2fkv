# Iwwerpréiwen records

`issue/` ass d'Iwwerpréiwung Board während der Migratioun:

- `new/`: Entrée fir nei Kommentarer.
- `todo/`: Adoptéiert, op Entwécklung.
- `done/`: Entwéckelt an huet Testbeweiser, amgaang iwwerpréiwen.
- `reviewed/`: Archiv iwwerpréift.
- `reject/`: Wann net ugeholl, gitt w.e.g. d'Grënn.

Kuckt `issue/new.md`, `issue/run.md`, `issue/review.md` fir de Prozess.

D'Iwwerpréiwung konzentréiert sech op Verhalensdifferenzen, Formatkompatibilitéit, Leeschtung a Codestruktur tëscht fkv an C++ Implementatiounen. Eng Meenung pro
Dateien fir grouss Beweegungen ze vermeiden.
