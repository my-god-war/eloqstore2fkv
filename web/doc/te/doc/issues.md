# రికార్డులను సమీక్షించండి

`issue/` అనేది మైగ్రేషన్ సమయంలో సమీక్ష బోర్డు:

- `new/`: కొత్త వ్యాఖ్యల కోసం ఎంట్రీ.
- `todo/`: స్వీకరించబడింది, పెండింగ్‌లో ఉన్న అభివృద్ధి.
- `done/`: అభివృద్ధి చేయబడింది మరియు పరీక్ష సాక్ష్యాన్ని కలిగి ఉంది, సమీక్ష పెండింగ్‌లో ఉంది.
- `reviewed/`: ఆర్కైవ్ సమీక్షించబడింది.
- `reject/`: ఆమోదించబడకపోతే, దయచేసి కారణాలను తెలియజేయండి.

ప్రక్రియ కోసం `issue/new.md`, `issue/run.md`, `issue/review.md` చూడండి.

సమీక్ష ప్రవర్తనా వ్యత్యాసాలు, ఫార్మాట్ అనుకూలత, పనితీరు మరియు fkv మరియు C++ అమలుల మధ్య కోడ్ నిర్మాణంపై దృష్టి పెడుతుంది. ఒక్కో అభిప్రాయం
బల్క్ కదలికలను నివారించడానికి ఫైల్‌లు.
