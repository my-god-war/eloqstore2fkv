# eloqstore2fkv

eloqstore నుండి fkvకి మైగ్రేషన్ మరియు అనుకూలత ధృవీకరణ గిడ్డంగి.

ప్రధాన fkv రిపోజిటరీ స్వచ్ఛమైన రస్ట్‌గా మిగిలిపోయింది మరియు స్వతంత్రంగా నిర్మించబడింది; ఈ రిపోజిటరీ C++ రిఫరెన్స్ ఇంప్లిమెంటేషన్ ఒరాకిల్, బైడైరెక్షనల్ బైట్ కార్పస్,
లెడ్జర్‌లు, హిస్టారికల్ ఆడిట్ రికార్డ్‌లను మైగ్రేట్ చేయండి మరియు CIని ధృవీకరించండి.

## కంటెంట్

- C++ ఒరాకిల్: లింక్ eloqstore ఫార్మాట్ లేయర్ మరియు పేజీ/ఇండెక్స్/ఓవర్‌ఫ్లో/మానిఫెస్ట్/ని రూపొందించండి
  కంప్రెస్ కార్పస్.
- ద్వి దిశాత్మక కార్పస్: C++ రైట్ → రస్ట్ రీడ్, రస్ట్ రైట్ → C++ రీడ్.
- `fkv_compat`: రస్ట్-సైడ్ అనుకూలత పరీక్ష, fkv వేర్‌హౌస్ ఫార్మాట్ క్రేట్‌పై ఆధారపడి ఉంటుంది.
- `fkv_ledger`: eloqstore స్కాన్ చేయండి, మైగ్రేషన్ లెడ్జర్‌ను రికార్డ్ చేయండి, కార్పస్‌ను రూపొందించండి మరియు ధృవీకరించండి.
- పనితీరు పోలిక: ఒకే పనిభారం కింద fkv మరియు C++ బేస్‌లైన్‌లను సరిపోల్చండి.
