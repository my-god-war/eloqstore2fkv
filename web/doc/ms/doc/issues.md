# Semak rekod

`issue/` ialah papan semakan semasa penghijrahan:

- `new/`: Kemasukan untuk ulasan baharu.
- `todo/`: Diguna pakai, pembangunan belum selesai.
- `done/`: Dibangunkan dan mempunyai bukti ujian, menunggu semakan.
- `reviewed/`: Arkib disemak.
- `reject/`: Jika tidak diterima pakai, sila nyatakan sebabnya.

Lihat `issue/new.md`, `issue/run.md`, `issue/review.md` untuk proses tersebut.

Semakan memfokuskan pada perbezaan tingkah laku, keserasian format, prestasi dan struktur kod antara pelaksanaan fkv dan C++. Satu pendapat per
fail untuk mengelakkan pergerakan pukal.
