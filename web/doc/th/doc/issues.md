# ตรวจสอบบันทึก

`issue/` เป็นคณะกรรมการตรวจสอบระหว่างการโยกย้าย:

- `new/`: รายการสำหรับความคิดเห็นใหม่
- `todo/`: นำมาใช้แล้ว รอการพัฒนา
- `done/`: ได้รับการพัฒนาและมีหลักฐานการทดสอบ รอการตรวจสอบ
- `reviewed/`: ตรวจสอบที่เก็บถาวรแล้ว
- `reject/`: หากไม่นำมาใช้ โปรดระบุเหตุผล

ดู `issue/new.md`, `issue/run.md`, `issue/review.md` สำหรับกระบวนการ

การตรวจสอบมุ่งเน้นไปที่ความแตกต่างด้านพฤติกรรม ความเข้ากันได้ของรูปแบบ ประสิทธิภาพ และโครงสร้างโค้ดระหว่างการใช้งาน fkv และ C++ ความเห็นละหนึ่งความเห็น
ไฟล์เพื่อหลีกเลี่ยงการย้ายจำนวนมาก
