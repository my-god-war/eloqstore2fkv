# eloqstore2fkv

คลังข้อมูลการตรวจสอบการโยกย้ายและความเข้ากันได้จาก eloqstore ไปยัง fkv

พื้นที่เก็บข้อมูล fkv หลักยังคงเป็น Rust บริสุทธิ์และสร้างขึ้นอย่างอิสระ พื้นที่เก็บข้อมูลนี้ยังคงใช้ Oracle การดำเนินการอ้างอิง C++, คลังข้อมูลไบต์แบบสองทิศทาง
ย้ายบัญชีแยกประเภท บันทึกการตรวจสอบในอดีต และตรวจสอบ CI

## เนื้อหา

- C ++ oracle: เชื่อมโยงเลเยอร์รูปแบบ eloqstore และสร้างหน้า / ดัชนี / ล้น / รายการ /
  บีบอัดคลังข้อมูล
- คลังข้อมูลแบบสองทิศทาง: เขียน C++ → อ่านสนิม เขียนสนิม → อ่าน C++
- `fkv_compat`: การทดสอบความเข้ากันได้ด้านสนิม โดยอาศัยรูปแบบของคลังสินค้า fkv
- `fkv_ledger`: สแกน eloqstore บันทึกบัญชีแยกประเภทการโยกย้าย สร้างและตรวจสอบคลังข้อมูล
- การเปรียบเทียบประสิทธิภาพ: เปรียบเทียบพื้นฐาน fkv และ C++ ภายใต้เวิร์กโหลดเดียวกัน
