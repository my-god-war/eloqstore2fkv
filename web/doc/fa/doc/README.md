# eloqstore2fkv

انبار تایید مهاجرت و سازگاری از eloqstore به fkv.

مخزن اصلی fkv Rust خالص باقی می ماند و به طور مستقل ساخته می شود. این مخزن اوراکل پیاده سازی مرجع C++، مجموعه بایت دو طرفه را حفظ می کند.
دفاتر کل، سوابق حسابرسی تاریخی را مهاجرت کنید و CI را تأیید کنید.

## محتوا

- اوراکل C++: لایه فرمت eloqstore را پیوند داده و صفحه/ایندکس/سرریز/مانیفست/ را ایجاد می کند
  فشرده سازی جسم
- پیکره دو طرفه: نوشتن C++ → Rust read، Rust write → C++ read.
- `fkv_compat`: تست سازگاری با سمت زنگ، با تکیه بر جعبه قالب انبار fkv.
- `fkv_ledger`: eloqstore را اسکن کنید، دفتر کل مهاجرت را ثبت کنید، مجموعه را ایجاد و تأیید کنید.
- مقایسه عملکرد: خطوط پایه fkv و C++ را با حجم کاری یکسان مقایسه کنید.
