# عملکرد

`perf-latest` از `fkv_bench` را از مخزن fkv دانلود کنید و همان حجم کاری را روی یک ماشین ثابت اجرا کنید.
و توان عملیاتی، چندک‌های تأخیر و پیک RSS را با خط پایه C++ مقایسه کنید.

منبع پارامتر با fkv سازگار است:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

خط پایه C++ توسط محیط اوراکل `simple_bench` اجرا می شود و سپس مطابق همان طرح خروجی می شود و در آن منتشر می شود.
`perf-baseline` دارایی آزاد. نتایج مقایسه در سند انبار نوشته می شود و سایت مستقیماً Markdown را ارائه می دهد.
هیچ لایه داده JSON نگهداری نمی شود.
