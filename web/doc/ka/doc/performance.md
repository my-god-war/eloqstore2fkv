# წარმადობა

ჩამოტვირთეთ `perf-latest` `fkv_bench`-დან fkv საცავიდან და გაუშვით იგივე დატვირთვა ფიქსირებულ აპარატზე.
და შეადარეთ გამტარუნარიანობა, შეყოვნების კვანტილები და RSS პიკი C++ საბაზისო ხაზთან.

პარამეტრის წყარო შეესაბამება fkv-ს:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

C++ საწყისს მართავს ორაკულის გარემო `simple_bench` და შემდეგ გამოდის იმავე სქემის მიხედვით და ქვეყნდება
`perf-baseline` გამოშვების აქტივი. შედარების შედეგები იწერება საწყობის დოკუმენტში და საიტი პირდაპირ ასახავს Markdown-ს.
JSON მონაცემთა ფენა არ არის შენარჩუნებული.
