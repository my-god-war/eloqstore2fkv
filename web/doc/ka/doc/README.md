# eloqstore2fkv

მიგრაციისა და თავსებადობის შემოწმების საწყობი eloqstore-დან fkv-მდე.

მთავარი fkv საცავი რჩება სუფთა Rust და აგებულია დამოუკიდებლად; ეს საცავი ინახავს C++ მითითების განხორციელების ორაკულს, ორმხრივი ბაიტის კორპუსს,
გადაიტანეთ წიგნები, ისტორიული აუდიტის ჩანაწერები და გადაამოწმეთ CI.

## შინაარსი

- C++ Oracle: დააკავშირეთ eloqstore ფორმატის ფენა და გენერირება გვერდი / ინდექსი / overflow / მანიფესტი /
  კორპუსის შეკუმშვა.
- ორმხრივი კორპუსი: C++ ჩაწერა → Rust read, Rust write → C++ read.
- `fkv_compat`: Rust-ის თავსებადობის ტესტი, რომელიც ეყრდნობა fkv საწყობის ფორმატის ყუთს.
- `fkv_ledger`: eloqstore-ის სკანირება, მიგრაციის წიგნის ჩაწერა, კორპუსის გენერირება და გადამოწმება.
- შესრულების შედარება: შეადარეთ fkv და C++ საბაზისო ხაზები იმავე დატვირთვის ქვეშ.
