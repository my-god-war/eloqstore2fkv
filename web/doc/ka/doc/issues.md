# გადახედეთ ჩანაწერებს

`issue/` არის მიმოხილვის დაფა მიგრაციის დროს:

- `new/`: შესვლა ახალი კომენტარებისთვის.
- `todo/`: მიღებულია, ელოდება განვითარებას.
- `done/`: შემუშავებული და აქვს სატესტო მტკიცებულება, ელოდება განხილვას.
- `reviewed/`: არქივი განხილულია.
- `reject/`: თუ არ იქნა მიღებული, გთხოვთ, მიუთითოთ მიზეზები.

პროცესისთვის იხილეთ `issue/new.md`, `issue/run.md`, `issue/review.md`.

მიმოხილვა ფოკუსირებულია ქცევითი განსხვავებები, ფორმატის თავსებადობა, შესრულება და კოდის სტრუქტურა fkv და C++ განხორციელებებს შორის. ერთი აზრი თითო
ფაილები ნაყარი გადაადგილების თავიდან ასაცილებლად.
