# eloqstore2fkv

eloqstore سے fkv تک منتقلی اور مطابقت کی تصدیق کا گودام۔

مرکزی fkv ذخیرہ خالص زنگ رہتا ہے اور آزادانہ طور پر بنایا گیا ہے۔ یہ ذخیرہ C++ حوالہ کے نفاذ اوریکل، دو طرفہ بائٹ کارپس کو برقرار رکھتا ہے،
لیجرز، تاریخی آڈٹ ریکارڈز کو منتقل کریں اور CI کی تصدیق کریں۔

## مواد

- C++ اوریکل: eloqstore فارمیٹ پرت کو لنک کریں اور صفحہ/انڈیکس/اوور فلو/مینیفسٹ/ تیار کریں
  کمپریس کارپس.
- دو طرفہ کارپس: C++ لکھنا → زنگ پڑھنا، زنگ لکھنا → C++ پڑھنا۔
- `fkv_compat`: Fkv گودام کے فارمیٹ کریٹ پر انحصار کرتے ہوئے، زنگ کی طرف مطابقت کا ٹیسٹ۔
- `fkv_ledger`: eloqstore اسکین کریں، مائیگریشن لیجر ریکارڈ کریں، کارپس بنائیں اور تصدیق کریں۔
- کارکردگی کا موازنہ: ایک ہی کام کے بوجھ کے تحت fkv اور C++ بیس لائنوں کا موازنہ کریں۔
