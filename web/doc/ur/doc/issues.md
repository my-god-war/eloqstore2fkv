# ریکارڈز کا جائزہ لیں۔

`issue/` منتقلی کے دوران جائزہ بورڈ ہے:

- `new/`: نئے تبصروں کے لیے اندراج۔
- `todo/`: اپنایا گیا، زیر التواء ترقی۔
- `done/`: تیار شدہ اور جانچ کے ثبوت ہیں، زیر التواء جائزہ۔
- `reviewed/`: آرکائیو کا جائزہ لیا گیا۔
- `reject/`: اگر اختیار نہیں کیا گیا تو براہ کرم وجوہات بیان کریں۔

عمل کے لیے `issue/new.md`، `issue/run.md`، `issue/review.md` دیکھیں۔

جائزہ Fkv اور C++ کے نفاذ کے درمیان رویے کے فرق، فارمیٹ کی مطابقت، کارکردگی، اور کوڈ کی ساخت پر مرکوز ہے۔ ایک رائے فی
بلک حرکتوں سے بچنے کے لیے فائلیں
