# eloqstore2fkv

माइग्रेसन र अनुकूलता प्रमाणिकरण गोदाम eloqstore देखि fkv मा।

मुख्य fkv भण्डार शुद्ध रस्ट रहन्छ र स्वतन्त्र रूपमा बनाइएको छ; यो भण्डारले C++ सन्दर्भ कार्यान्वयन ओरेकल, द्विदिशात्मक बाइट कोर्पस राख्छ,
लेजरहरू माइग्रेट गर्नुहोस्, ऐतिहासिक लेखापरीक्षण अभिलेखहरू र CI प्रमाणित गर्नुहोस्।

## सामग्री

- C++ ओरेकल: eloqstore ढाँचा तह लिङ्क गर्नुहोस् र पृष्ठ/सूचकांक/ओभरफ्लो/म्यानिफेस्ट/ उत्पन्न गर्नुहोस्।
  कम्प्रेस कोष।
- द्विदिशात्मक कोष: C++ राइट → रस्ट रिड, रस्ट राइट → C++ पढ्नुहोस्।
- `fkv_compat`: रस्ट-साइड अनुकूलता परीक्षण, fkv गोदामको ढाँचा क्रेटमा भर पर्दै।
- `fkv_ledger`: eloqstore स्क्यान गर्नुहोस्, माइग्रेसन खाता रेकर्ड गर्नुहोस्, कोर्पस उत्पन्न गर्नुहोस् र प्रमाणित गर्नुहोस्।
- कार्यसम्पादन तुलना: समान कार्यभार अन्तर्गत fkv र C++ आधाररेखाहरू तुलना गर्नुहोस्।
