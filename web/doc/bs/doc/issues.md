# Pregledajte zapise

`issue/` je ploča za recenzije tokom migracije:

- `new/`: Unos za nove komentare.
- `todo/`: Usvojeno, čeka se razvoj.
- `done/`: Razvijen i ima test dokaze, čeka se pregled.
- `reviewed/`: Arhiva pregledana.
- `reject/`: Ako nije usvojeno, navedite razloge.

Pogledajte `issue/new.md`, `issue/run.md`, `issue/review.md` za proces.

Pregled se fokusira na razlike u ponašanju, kompatibilnost formata, performanse i strukturu koda između fkv i C++ implementacija. Jedno mišljenje po
datoteke kako biste izbjegli masovna kretanja.
