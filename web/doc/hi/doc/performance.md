# प्रदर्शन

एफकेवी रिपॉजिटरी से `perf-latest` में से `fkv_bench` डाउनलोड करें और एक निश्चित मशीन पर समान वर्कलोड चलाएं।
और थ्रूपुट, विलंबता मात्रा और शिखर RSS की तुलना C++ बेसलाइन से करें।

पैरामीटर स्रोत fkv के अनुरूप है:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

C++ बेसलाइन को ओरेकल वातावरण `simple_bench` द्वारा चलाया जाता है और फिर उसी स्कीमा के अनुसार आउटपुट दिया जाता है और प्रकाशित किया जाता है।
`perf-baseline` संपत्ति जारी करें। तुलना परिणाम वापस वेयरहाउस दस्तावेज़ में लिखे जाते हैं, और साइट सीधे मार्कडाउन प्रस्तुत करती है।
कोई JSON डेटा स्तर बनाए नहीं रखा गया है.
