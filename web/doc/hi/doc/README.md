# eloqstore2fkv

eloqstore से fkv में स्थानांतरण और अनुकूलता सत्यापन गोदाम।

मुख्य एफकेवी भंडार शुद्ध जंग बना हुआ है और स्वतंत्र रूप से बनाया गया है; यह भंडार C++ संदर्भ कार्यान्वयन ओरेकल, द्विदिशात्मक बाइट कॉर्पस को बरकरार रखता है,
बही-खाते, ऐतिहासिक ऑडिट रिकॉर्ड को स्थानांतरित करें और सीआई को सत्यापित करें।

## सामग्री

- C++ ओरेकल: eloqstore फॉर्मेट लेयर को लिंक करें और पेज/इंडेक्स/ओवरफ्लो/मेनिफ़ेस्ट/ जेनरेट करें
  कोष को संपीड़ित करें.
- द्विदिशात्मक कॉर्पस: C++ लिखना → जंग पढ़ना, जंग लिखना → C++ पढ़ना।
- `fkv_compat`: जंग-पक्ष संगतता परीक्षण, एफकेवी गोदाम के प्रारूप क्रेट पर निर्भर।
- `fkv_ledger`: eloqstore को स्कैन करें, माइग्रेशन लेजर रिकॉर्ड करें, कॉर्पस बनाएं और सत्यापित करें।
- प्रदर्शन तुलना: समान कार्यभार के तहत fkv और C++ बेसलाइन की तुलना करें।
