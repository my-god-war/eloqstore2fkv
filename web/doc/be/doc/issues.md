# Агляд запісаў

`issue/` - дошка агляду падчас міграцыі:

- `new/`: Запіс для новых каментарыяў.
- `todo/`: Прынята, чакае распрацоўкі.
- `done/`: Распрацавана і мае доказы тэставання, чакае разгляду.
- `reviewed/`: Архіў прагледжаны.
- `reject/`: Калі не прынята, укажыце прычыны.

Пра працэс гл. `issue/new.md`, `issue/run.md`, `issue/review.md`.

Агляд прысвечаны адрозненням у паводзінах, сумяшчальнасці фарматаў, прадукцыйнасці і структуры кода паміж рэалізацыямі fkv і C++. Адно меркаванне за
файлы, каб пазбегнуць масавых перамяшчэнняў.
