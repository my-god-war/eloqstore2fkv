# eloqstore2fkv

Сховішча пераносу і праверкі сумяшчальнасці з eloqstore на fkv.

Галоўнае сховішча fkv застаецца чыстым Rust і ствараецца незалежна; гэта сховішча захоўвае эталонную рэалізацыю C++ Oracle, двухнакіраваны байтавы корпус,
Перанос бухгалтарскіх кніг, гістарычных запісаў аўдыту і праверка CI.

## змест

- C++ oracle: звяжыце ўзровень фармату eloqstore і згенеруйце старонку/індэкс/перапаўненне/маніфест/
  сціснуць корпус.
- Двунакіраваны корпус: C++ запіс → Rust чытанне, Rust запіс → C++ чытанне.
- `fkv_compat`: тэст на сумяшчальнасць з бокам Rust, абапіраючыся на скрыню фармату склада fkv.
- `fkv_ledger`: сканаванне eloqstore, запіс міграцыйнай кнігі, стварэнне і праверка корпуса.
- Параўнанне прадукцыйнасці: параўнайце базавыя паказчыкі fkv і C++ пры аднолькавай нагрузцы.
