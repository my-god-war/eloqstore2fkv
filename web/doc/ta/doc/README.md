# eloqstore2fkv

eloqstore இலிருந்து fkv க்கு இடம்பெயர்வு மற்றும் பொருந்தக்கூடிய சரிபார்ப்பு கிடங்கு.

முக்கிய fkv களஞ்சியம் தூய்மையான துருவாக உள்ளது மற்றும் சுயாதீனமாக கட்டப்பட்டுள்ளது; இந்த களஞ்சியம் C++ குறிப்பு செயல்படுத்தல் ஆரக்கிள், இருதரப்பு பைட் கார்பஸ்,
லெட்ஜர்கள், வரலாற்று தணிக்கை பதிவுகள் மற்றும் CI ஐ சரிபார்க்கவும்.

## உள்ளடக்கம்

- C++ ஆரக்கிள்: இணைப்பு eloqstore வடிவமைப்பு அடுக்கு மற்றும் பக்கம்/இண்டெக்ஸ்/ஓவர்ஃப்ளோ/மேனிஃபெஸ்ட்/ உருவாக்கவும்
  சுருக்க கார்பஸ்.
- இருதரப்பு கார்பஸ்: சி++ எழுது → ரஸ்ட் ரீட், ரஸ்ட் ரைட் → சி++ படிக்க.
- `fkv_compat`: fkv கிடங்கின் வடிவமைப்புக் கூட்டை நம்பியிருக்கும் ரஸ்ட்-சைட் இணக்கத்தன்மை சோதனை.
- `fkv_ledger`: eloqstore ஐ ஸ்கேன் செய்யவும், இடம்பெயர்வு லெட்ஜரைப் பதிவு செய்யவும், கார்பஸை உருவாக்கி சரிபார்க்கவும்.
- செயல்திறன் ஒப்பீடு: அதே பணிச்சுமையின் கீழ் fkv மற்றும் C++ அடிப்படைகளை ஒப்பிடுக.
