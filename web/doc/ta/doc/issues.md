# பதிவுகளை மதிப்பாய்வு செய்யவும்

இடம்பெயர்வின் போது `issue/` மதிப்பாய்வு குழு:

- `new/`: புதிய கருத்துகளுக்கான நுழைவு.
- `todo/`: ஏற்றுக்கொள்ளப்பட்டது, நிலுவையில் உள்ள வளர்ச்சி.
- `done/`: உருவாக்கப்பட்டது மற்றும் சோதனை ஆதாரம் உள்ளது, மதிப்பாய்வு நிலுவையில் உள்ளது.
- `reviewed/`: காப்பகம் மதிப்பாய்வு செய்யப்பட்டது.
- `reject/`: ஏற்றுக்கொள்ளப்படவில்லை என்றால், காரணங்களைக் குறிப்பிடவும்.

செயல்முறைக்கு `issue/new.md`, `issue/run.md`, `issue/review.md` ஐப் பார்க்கவும்.

மதிப்பாய்வு நடத்தை வேறுபாடுகள், வடிவமைப்பு இணக்கத்தன்மை, செயல்திறன் மற்றும் fkv மற்றும் C++ செயலாக்கங்களுக்கு இடையேயான குறியீடு அமைப்பு ஆகியவற்றில் கவனம் செலுத்துகிறது. ஒன்றுக்கு ஒரு கருத்து
மொத்த நகர்வுகளைத் தவிர்க்க கோப்புகள்.
