# Revisar rexistros

`issue/` é o comité de revisión durante a migración:

- `new/`: entrada para comentarios novos.
- `todo/`: Adoptado, pendente de desenvolvemento.
- `done/`: desenvolvido e ten probas de proba, pendente de revisión.
- `reviewed/`: Arquivo revisado.
- `reject/`: se non se adopta, indique os motivos.

Consulte `issue/new.md`, `issue/run.md`, `issue/review.md` para coñecer o proceso.

A revisión céntrase nas diferenzas de comportamento, compatibilidade de formato, rendemento e estrutura de código entre as implementacións de fkv e C++. Unha opinión por
ficheiros para evitar movementos masivos.
