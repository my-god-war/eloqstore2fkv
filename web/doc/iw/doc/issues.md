# עיין ברשומות

`issue/` הוא לוח הביקורת במהלך ההעברה:

- `new/`: כניסה להערות חדשות.
- `todo/`: אומץ, ממתין לפיתוח.
- `done/`: פותח ויש לו ראיות בדיקה, בהמתנה לבדיקה.
- `reviewed/`: הארכיון נבדק.
- `reject/`: אם לא אומץ, נא לציין את הסיבות.

ראה `issue/new.md`, `issue/run.md`, `issue/review.md` לתהליך.

הסקירה מתמקדת בהבדלים התנהגותיים, תאימות פורמט, ביצועים ומבנה קוד בין יישומי fkv ו-C++. דעה אחת לכל
קבצים כדי למנוע מהלכים בכמות גדולה.
