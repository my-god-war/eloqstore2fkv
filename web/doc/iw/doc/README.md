# eloqstore2fkv

מחסן הגירה ואימות תאימות מ- eloqstore ל-fkv.

מאגר fkv הראשי נשאר Rust טהור והוא בנוי באופן עצמאי; מאגר זה שומר על אורקל המימוש C++, קורפוס בתים דו-כיווני,
העבר ספרי חשבונות, רשומות ביקורת היסטוריות ואמת CI.

## תוֹכֶן

- C++ oracle: קישור שכבת פורמט eloqstore ויצירת עמוד/אינדקס/overflow/manifest/
  לדחוס קורפוס.
- קורפוס דו-כיווני: C++ כתיבה ← קריאה חלודה, כתיבה חלודה ← C++ קריאה.
- `fkv_compat`: בדיקת תאימות לצד חלודה, בהסתמך על ארגז הפורמט של מחסן fkv.
- `fkv_ledger`: סרוק את eloqstore, רשום את ספר ההגירה, צור ואמת קורפוס.
- השוואת ביצועים: השווה קווי בסיס של fkv ו-C++ תחת אותו עומס עבודה.
