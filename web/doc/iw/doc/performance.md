# ביצועים

הורד את `perf-latest` של `fkv_bench` ממאגר fkv והפעל את אותו עומס עבודה על מחשב קבוע.
והשווה תפוקה, כמות חביון ושיא RSS לקו הבסיס של C++.

מקור הפרמטר תואם fkv:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

קו הבסיס של C++ מנוהל על ידי סביבת האורקל `simple_bench` ולאחר מכן פלט לפי אותה סכימה ומפורסם ל
`perf-baseline` נכס שחרור. תוצאות ההשוואה נכתבות בחזרה למסמך המחסן, והאתר מעבד ישירות את Markdown.
לא נשמרת שכבת נתונים של JSON.
