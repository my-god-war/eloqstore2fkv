# Pārskatiet ierakstus

`issue/` ir pārskatīšanas panelis migrācijas laikā:

- `new/`: ieraksts jauniem komentāriem.
- `todo/`: pieņemts, gaida izstrādi.
- `done/`: izstrādāts, un tam ir pārbaudes pierādījumi, gaida pārskatīšanu.
- `reviewed/`: arhīvs pārskatīts.
- `reject/`: ja nav pieņemts, lūdzu, norādiet iemeslus.

Par procesu skatiet `issue/new.md`, `issue/run.md`, `issue/review.md`.

Pārskatā galvenā uzmanība pievērsta uzvedības atšķirībām, formātu saderībai, veiktspējai un koda struktūrai starp fkv un C++ implementācijām. Viens viedoklis per
failus, lai izvairītos no lielapjoma pārvietošanas.
