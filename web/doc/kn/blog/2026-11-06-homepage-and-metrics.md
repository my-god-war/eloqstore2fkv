# 2026-11-06: ಮುಖಪುಟದ ಕಾರ್ಯಕ್ಷಮತೆ ಕೋಷ್ಟಕ, ಸೂಚಕ ವಿಸ್ತರಣೆ ಮತ್ತು ಪುಟಗಳು

ಇಂದಿನ ನವೀಕರಣವು ಕಾರ್ಯಕ್ಷಮತೆಯ ವಿಮರ್ಶೆಗಳು ಮತ್ತು ಸೈಟ್ ಲಾಂಚ್‌ಗಳ ಮೇಲೆ ಕೇಂದ್ರೀಕರಿಸುತ್ತದೆ.

## ಮುಖಪುಟದ ಕಾರ್ಯಕ್ಷಮತೆಯ ಹೋಲಿಕೆ

- ಮುಖಪುಟವನ್ನು ಕಾರ್ಯಕ್ಷಮತೆಯ ಆದ್ಯತೆಗೆ ಬದಲಾಯಿಸಲಾಗಿದೆ, ಮತ್ತು C++/Rust ಹೋಲಿಕೆ ಕೋಷ್ಟಕವನ್ನು ನೇರವಾಗಿ ಮೊದಲ ಪರದೆಯಲ್ಲಿ ಪ್ರದರ್ಶಿಸಲಾಗುತ್ತದೆ.
- ಮೂರು ಹೊಸ ಸೆಟ್ ಸೂಚಕಗಳನ್ನು ಸೇರಿಸಲಾಗಿದೆ: ತಾರ್ಕಿಕ ಬ್ಯಾಂಡ್‌ವಿಡ್ತ್, P99.9 ಟೈಲ್ ವಿಳಂಬ, ಮತ್ತು ಪ್ರಾದೇಶಿಕ ವರ್ಧನೆ.
- ರಸ್ಟ್ ಚಾಲನೆಯಲ್ಲಿರುವ ವಿವರಗಳನ್ನು ಸೇರಿಸಲಾಗಿದೆ: ಸ್ಕ್ಯಾನ್, ಫುಲ್‌ಸ್ಕನ್, ರೈಟ್ ಆಂಪ್ಲಿಫಿಕೇಶನ್, ರೈಟ್ ಸಿಸ್ಟಮ್ ಕರೆಗಳ ಸಂಖ್ಯೆ ಮತ್ತು ಪ್ರತಿ ಬ್ಯಾಚ್‌ಗೆ ಡೇಟಾ ಸಿಂಕ್ರೊನೈಸೇಶನ್.
- `write-read` ಅನ್ನು ಮಿಶ್ರ ಕ್ಯಾಲಿಬರ್ ಎಂದು ಸ್ಪಷ್ಟವಾಗಿ ಗುರುತಿಸಿ ಮತ್ತು ಕಾರ್ಯಕ್ಷಮತೆಯ ದಾಖಲಾತಿಗೆ ಲಿಂಕ್ ಮಾಡಿ.

## ಮೌಲ್ಯಮಾಪನ ಸೂಚಕಗಳು

RocksDB, LevelDB, YCSB, WiredTiger ಮತ್ತು ಇತರ ಮಾನದಂಡಗಳ ಸಾಮಾನ್ಯ ಔಟ್‌ಪುಟ್ ಅನ್ನು ಉಲ್ಲೇಖಿಸಿ, ನಾನು ಸೇರಿಸಿದ್ದೇನೆ:

- ತಾರ್ಕಿಕ ಓದುವ ಮತ್ತು ಬರೆಯುವ ಬ್ಯಾಂಡ್‌ವಿಡ್ತ್ MiB/s;
- P99.9 ಬಾಲ ವಿಳಂಬ;
- ಬಾಹ್ಯಾಕಾಶ ವರ್ಧನೆ, ಬರವಣಿಗೆ ವರ್ಧನೆ;
- ಪ್ರತಿ ಬ್ಯಾಚ್‌ನಲ್ಲಿ ಸಿಸ್ಟಮ್ ಕರೆಗಳು ಮತ್ತು ಡೇಟಾ ಸಿಂಕ್ರೊನೈಸೇಶನ್ ಬರೆಯುವ ಸಂಖ್ಯೆ;
- ಸ್ಕ್ಯಾನ್ / ಫುಲ್‌ಸ್ಕ್ಯಾನ್ ಥ್ರೋಪುಟ್;
- CPU, ಪುಟ ದೋಷಗಳು, ಸಂದರ್ಭ ಸ್ವಿಚ್‌ಗಳು ಮತ್ತು ಪ್ರಕ್ರಿಯೆ IO ಅನ್ನು ಸಂಪನ್ಮೂಲ ಸೈಡ್‌ಕಾರ್ ಸಂಗ್ರಹಿಸುವುದನ್ನು ಮುಂದುವರಿಸುತ್ತದೆ.

ಅದೇ ಸಮಯದಲ್ಲಿ`gxhash_4096B_gib_s` ನಿವೃತ್ತರಾದರು. ಇದು 4 KiB ಸಿಂಗಲ್ ಬ್ಲಾಕ್ ಹ್ಯಾಶ್ ಮೈಕ್ರೋಬೆಂಚ್‌ಮಾರ್ಕ್ ಆಗಿದ್ದು ಅದು KV ಎಂಜಿನ್ ಪಥದಲ್ಲಿಲ್ಲ ಮತ್ತು C++ ಪ್ರತಿರೂಪವನ್ನು ಹೊಂದಿಲ್ಲ.

## ನಿಖರತೆ ಮತ್ತು ಎಂಜಿನಿಯರಿಂಗ್ ಪರಿಹಾರಗಳು

- `--rng cpp` ರೀಡ್/ಸ್ಕ್ಯಾನ್‌ನ ಕೀ ಸ್ಪೇಸ್ ಅನ್ನು ಸರಿಪಡಿಸಿ: 75% ರೀಡ್‌ಗಳು ಅಲಿಖಿತ ಕೀಗಳಲ್ಲಿ ಬೀಳುವುದನ್ನು ತಪ್ಪಿಸಲು ರೀಡ್ ಡಿಟೆಕ್ಷನ್ ಅನ್ನು ಇನ್ನು ಮುಂದೆ `key_interval` ನಿಂದ ಗುಣಿಸಲಾಗುವುದಿಲ್ಲ.
- MacOS `openrsync` ಒಂದೇ ವಿಷಯದೊಂದಿಗೆ ಮ್ಯಾನಿಫೆಸ್ಟ್‌ಗಳ ತಪ್ಪು ನಿರ್ಣಯದಿಂದ ಉಂಟಾಗುವ ಸ್ಥಿರ ಸ್ಟ್ಯಾಂಡ್‌ಬೈ ಮರುಪ್ರಯತ್ನಗಳು.
- QEMU ವರ್ಚುವಲ್ ಡಿಸ್ಕ್‌ಗಳನ್ನು ಸ್ಥಳೀಯ SSD ಗಳೆಂದು ತಪ್ಪಾಗಿ ನಿರ್ಣಯಿಸಿದ ಹಾರ್ಡ್‌ವೇರ್ ಗೇಟ್ ಸಮಸ್ಯೆಯನ್ನು ಪರಿಹರಿಸಲಾಗಿದೆ.

## ಸೈಟ್ಗಳು ಮತ್ತು ಪ್ರಕಾಶನ

- GitHub ಪುಟಗಳನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಲಾಗಿದೆ: <https://my-god-war.github.io/eloqstore2fkv/>
- ಸೈಟ್ ರೂಟಿಂಗ್ `/eloqstore2fkv/` ಉಪಪಥಗಳನ್ನು ಬೆಂಬಲಿಸುತ್ತದೆ.
- ಬದಲಿಗೆ ಡಾಕ್ಯುಮೆಂಟ್ ಅನ್ನು `raw.githubusercontent.com` ನಿಂದ ಓದಲಾಗುತ್ತದೆ ಮತ್ತು jsDelivr ಪಥದಲ್ಲಿ `web/` ಕಾಣೆಯಾದ ಕಾರಣ 404 ಅನ್ನು ಸರಿಪಡಿಸಲಾಗಿದೆ.
- ಬ್ಲಾಗ್ ನ್ಯಾವಿಗೇಶನ್ ಮತ್ತು `bun run tran` ಬಹು-ಭಾಷಾ ಅನುವಾದವನ್ನು ಸಂಯೋಜಿಸಲಾಗಿದೆ; ಈ ಲೇಖನವನ್ನು ಚೀನೀ ಮೂಲದಿಂದ ಇತರ ಭಾಷೆಗಳಿಗೆ ಸ್ವಯಂಚಾಲಿತವಾಗಿ ಅನುವಾದಿಸಲಾಗುತ್ತದೆ.

ನಂತರದ ಚೇಂಜ್‌ಲಾಗ್‌ಗಳು ಹೊಂದಾಣಿಕೆ, ಕಾರ್ಯಕ್ಷಮತೆ ಮತ್ತು ಟೂಲ್‌ಚೈನ್ ಬದಲಾವಣೆಗಳನ್ನು ದಾಖಲಿಸಲು ಮುಂದುವರಿಯುತ್ತದೆ.
