# eloqstore2fkv

eloqstore ನಿಂದ fkv ಗೆ ವಲಸೆ ಮತ್ತು ಹೊಂದಾಣಿಕೆ ಪರಿಶೀಲನೆ ಗೋದಾಮು.

ಮುಖ್ಯ fkv ರೆಪೊಸಿಟರಿಯು ಶುದ್ಧ ರಸ್ಟ್ ಆಗಿ ಉಳಿದಿದೆ ಮತ್ತು ಸ್ವತಂತ್ರವಾಗಿ ನಿರ್ಮಿಸಲಾಗಿದೆ; ಈ ರೆಪೊಸಿಟರಿಯು C++ ರೆಫರೆನ್ಸ್ ಇಂಪ್ಲಿಮೆಂಟೇಶನ್ ಒರಾಕಲ್, ಬೈಡೈರೆಕ್ಷನಲ್ ಬೈಟ್ ಕಾರ್ಪಸ್ ಅನ್ನು ಉಳಿಸಿಕೊಂಡಿದೆ,
ಲೆಡ್ಜರ್‌ಗಳು, ಐತಿಹಾಸಿಕ ಆಡಿಟ್ ದಾಖಲೆಗಳನ್ನು ಸ್ಥಳಾಂತರಿಸಿ ಮತ್ತು CI ಅನ್ನು ಪರಿಶೀಲಿಸಿ.

## ವಿಷಯ

- C++ ಒರಾಕಲ್: ಲಿಂಕ್ eloqstore ಫಾರ್ಮ್ಯಾಟ್ ಲೇಯರ್ ಮತ್ತು ಪುಟ/ಸೂಚ್ಯಂಕ/ಓವರ್‌ಫ್ಲೋ/ಮ್ಯಾನಿಫೆಸ್ಟ್/ ಅನ್ನು ರಚಿಸಿ
  ಸಂಕುಚಿತ ಕಾರ್ಪಸ್.
- ಬೈಡೈರೆಕ್ಷನಲ್ ಕಾರ್ಪಸ್: ಸಿ++ ಬರೆಯಿರಿ → ರಸ್ಟ್ ರೀಡ್, ರಸ್ಟ್ ರೈಟ್ → ಸಿ++ ರೀಡ್.
- `fkv_compat`: ರಸ್ಟ್-ಸೈಡ್ ಹೊಂದಾಣಿಕೆಯ ಪರೀಕ್ಷೆ, fkv ವೇರ್‌ಹೌಸ್‌ನ ಫಾರ್ಮ್ಯಾಟ್ ಕ್ರೇಟ್ ಅನ್ನು ಅವಲಂಬಿಸಿದೆ.
- `fkv_ledger`: eloqstore ಅನ್ನು ಸ್ಕ್ಯಾನ್ ಮಾಡಿ, ವಲಸೆ ಲೆಡ್ಜರ್ ಅನ್ನು ರೆಕಾರ್ಡ್ ಮಾಡಿ, ಕಾರ್ಪಸ್ ಅನ್ನು ರಚಿಸಿ ಮತ್ತು ಪರಿಶೀಲಿಸಿ.
- ಕಾರ್ಯಕ್ಷಮತೆಯ ಹೋಲಿಕೆ: ಒಂದೇ ಕೆಲಸದ ಹೊರೆ ಅಡಿಯಲ್ಲಿ fkv ಮತ್ತು C++ ಬೇಸ್‌ಲೈನ್‌ಗಳನ್ನು ಹೋಲಿಕೆ ಮಾಡಿ.
