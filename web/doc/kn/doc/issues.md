# ದಾಖಲೆಗಳನ್ನು ಪರಿಶೀಲಿಸಿ

`issue/` ವಲಸೆಯ ಸಮಯದಲ್ಲಿ ಪರಿಶೀಲನಾ ಮಂಡಳಿಯಾಗಿದೆ:

- `new/`: ಹೊಸ ಕಾಮೆಂಟ್‌ಗಳಿಗೆ ಪ್ರವೇಶ.
- `todo/`: ಅಳವಡಿಸಿಕೊಳ್ಳಲಾಗಿದೆ, ಅಭಿವೃದ್ಧಿ ಬಾಕಿಯಿದೆ.
- `done/`: ಅಭಿವೃದ್ಧಿಪಡಿಸಲಾಗಿದೆ ಮತ್ತು ಪರೀಕ್ಷಾ ಪುರಾವೆಗಳನ್ನು ಹೊಂದಿದೆ, ಪರಿಶೀಲನೆ ಬಾಕಿಯಿದೆ.
- `reviewed/`: ಆರ್ಕೈವ್ ಅನ್ನು ಪರಿಶೀಲಿಸಲಾಗಿದೆ.
- `reject/`: ಅಳವಡಿಸಿಕೊಳ್ಳದಿದ್ದರೆ, ದಯವಿಟ್ಟು ಕಾರಣಗಳನ್ನು ತಿಳಿಸಿ.

ಪ್ರಕ್ರಿಯೆಗಾಗಿ `issue/new.md`, `issue/run.md`, `issue/review.md` ನೋಡಿ.

ವಿಮರ್ಶೆಯು ನಡವಳಿಕೆಯ ವ್ಯತ್ಯಾಸಗಳು, ಫಾರ್ಮ್ಯಾಟ್ ಹೊಂದಾಣಿಕೆ, ಕಾರ್ಯಕ್ಷಮತೆ ಮತ್ತು fkv ಮತ್ತು C++ ಅನುಷ್ಠಾನಗಳ ನಡುವಿನ ಕೋಡ್ ರಚನೆಯ ಮೇಲೆ ಕೇಂದ್ರೀಕರಿಸುತ್ತದೆ. ಪ್ರತಿ ಒಂದು ಅಭಿಪ್ರಾಯ
ಬೃಹತ್ ಚಲನೆಗಳನ್ನು ತಪ್ಪಿಸಲು ಫೈಲ್‌ಗಳು.
