# Revise os registros

`issue/` é o conselho de revisão durante a migração:

- `new/`: Entrada para novos comentários.
- `todo/`: Adotado, desenvolvimento pendente.
- `done/`: Desenvolvido e possui evidências de teste, com revisão pendente.
- `reviewed/`: Arquivo revisado.
- `reject/`: Se não for adotado, indique os motivos.

Consulte `issue/new.md`, `issue/run.md`, `issue/review.md` para ver o processo.

A revisão se concentra nas diferenças comportamentais, compatibilidade de formato, desempenho e estrutura de código entre implementações de fkv e C++. Uma opinião por
arquivos para evitar movimentos em massa.
