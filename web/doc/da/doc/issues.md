# Gennemgå optegnelser

`issue/` er anmeldelsestavlen under migreringen:

- `new/`: Indgang for nye kommentarer.
- `todo/`: Vedtaget, afventer udvikling.
- `done/`: Udviklet og har testbeviser, afventer gennemgang.
- `reviewed/`: Arkiv gennemgået.
- `reject/`: Hvis det ikke er vedtaget, bedes du angive årsagerne.

Se `issue/new.md`, `issue/run.md`, `issue/review.md` for processen.

Gennemgangen fokuserer på adfærdsforskelle, formatkompatibilitet, ydeevne og kodestruktur mellem fkv og C++ implementeringer. En udtalelse pr
filer for at undgå masseflytninger.
