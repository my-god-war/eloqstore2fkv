# eloqstore2fkv

Складиште за миграцију и верификацију компатибилности са елоксторе на фкв.

Главно фкв спремиште остаје чисто Руст и изграђено је независно; ово спремиште задржава пророчиште имплементације Ц++ референце, двосмерни бајт корпус,
Мигрирајте књиге, историјске ревизијске записе и проверите ЦИ.

## садржаја

- Ц++ пророчиште: повежите слој формата елоксторе и генеришите страницу/индекс/прелив/манифест/
  компримовати корпус.
- Двосмерни корпус: Ц++ писање → Руст читање, Руст писање → Ц++ читање.
- <б ид="1">: Тест компатибилности на страни Руст-а, ослањајући се на кутију формата фкв складишта.
- <б ид="1">: Скенирајте елоксторе, забележите књигу миграције, генеришете и верификујте корпус.
- Поређење перформанси: Упоредите фкв и Ц++ основне линије под истим оптерећењем.
