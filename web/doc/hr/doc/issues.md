# Pregledajte zapise

`issue/` je ploča za pregled tijekom migracije:

- `new/`: Unos za nove komentare.
- `todo/`: Usvojeno, čeka razvoj.
- `done/`: Razvijeno i ima dokaze testiranja, čeka se pregled.
- `reviewed/`: Arhiva je pregledana.
- `reject/`: Ako nije usvojeno, navedite razloge.

Pogledajte `issue/new.md`, `issue/run.md`, `issue/review.md` za postupak.

Pregled se fokusira na razlike u ponašanju, kompatibilnost formata, izvedbu i strukturu koda između fkv i C++ implementacija. Jedno mišljenje po
datoteke kako biste izbjegli skupna premještanja.
