# Gjennomgå poster

`issue/` er vurderingstavlen under migrering:

- `new/`: Innlegg for nye kommentarer.
- `todo/`: Vedtatt, venter på utvikling.
- `done/`: Utviklet og har testbevis, venter på gjennomgang.
- `reviewed/`: Arkivet er gjennomgått.
- `reject/`: Hvis ikke vedtatt, vennligst oppgi grunnene.

Se `issue/new.md`, `issue/run.md`, `issue/review.md` for prosessen.

Gjennomgangen fokuserer på atferdsforskjeller, formatkompatibilitet, ytelse og kodestruktur mellom fkv- og C++-implementeringer. En mening pr
filer for å unngå masseflytting.
