# Revisar registros

`issue/` es la junta de revisión durante la migración:

- `new/`: Entrada para nuevos comentarios.
- `todo/`: Adoptado, pendiente de desarrollo.
- `done/`: Desarrollado y cuenta con evidencia de prueba, pendiente de revisión.
- `reviewed/`: Archivo revisado.
- `reject/`: Si no se adopta, indique los motivos.

Consulte `issue/new.md`, `issue/run.md`, `issue/review.md` para conocer el proceso.

La revisión se centra en las diferencias de comportamiento, compatibilidad de formatos, rendimiento y estructura de código entre las implementaciones de fkv y C++. Una opinión por
archivos para evitar movimientos masivos.
