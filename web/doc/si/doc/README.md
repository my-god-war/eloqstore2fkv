# eloqstore2fkv

eloqstore සිට fkv දක්වා සංක්‍රමණය සහ අනුකූලතා සත්‍යාපන ගබඩාව.

ප්‍රධාන fkv ගබඩාව පිරිසිදු මලකඩ ලෙස පවතින අතර ස්වාධීනව ගොඩනගා ඇත; මෙම ගබඩාව C++ යොමු ක්‍රියාත්මක කිරීමේ ඔරකල්, ද්විපාර්ශ්වික බයිට් කෝපස් රඳවා තබා ගනී,
ලෙජර, ඓතිහාසික විගණන වාර්තා සංක්‍රමණය කර CI සත්‍යාපනය කරන්න.

## අන්තර්ගතය

- C++ oracle: සබැඳි eloqstore ආකෘති ස්ථරය සහ පිටුව/දර්ශකය/පිටාර ගැලීම/මැනිෆෙස්ට්/ උත්පාදනය කරන්න
  සම්පීඩනය corpus.
- ද්විපාර්ශ්වික කෝපස්: C++ ලිවීම → මලකඩ කියවීම, මලකඩ ලිවීම → C++ කියවීම.
- `fkv_compat`: fkv ගබඩාවේ ආකෘති කූඩය මත රඳා පවතින මලකඩ-පැත්තේ අනුකූලතා පරීක්ෂණය.
- `fkv_ledger`: eloqstore පරිලෝකනය කරන්න, සංක්‍රමණ ලෙජරය වාර්තා කරන්න, corpus ජනනය කරන්න සහ සත්‍යාපනය කරන්න.
- කාර්ය සාධන සංසන්දනය: එකම කාර්ය භාරය යටතේ fkv සහ C++ මූලික රේඛා සසඳන්න.
