# වාර්තා සමාලෝචනය කරන්න

`issue/` යනු සංක්‍රමණය අතරතුර සමාලෝචන මණ්ඩලයයි:

- `new/`: නව අදහස් සඳහා ප්‍රවේශය.
- `todo/`: හදාගත්, අපේක්ෂිත සංවර්ධනය.
- `done/`: සංවර්ධනය කර ඇති අතර පරීක්ෂණ සාක්ෂි ඇත, සමාලෝචනය බලාපොරොත්තු වේ.
- `reviewed/`: සංරක්ෂිතය සමාලෝචනය කරන ලදී.
- `reject/`: සම්මත කර නොගන්නේ නම්, කරුණාකර හේතු දක්වන්න.

ක්‍රියාවලිය සඳහා `issue/new.md`, `issue/run.md`, `issue/review.md` බලන්න.

සමාලෝචනය fkv සහ C++ ක්‍රියාත්මක කිරීම් අතර හැසිරීම් වෙනස්කම්, ආකෘති ගැළපුම, කාර්ය සාධනය සහ කේත ව්‍යුහය කෙරෙහි අවධානය යොමු කරයි. එක් මතයක් අනුව
තොග චලනයන් වළක්වා ගැනීමට ගොනු.
