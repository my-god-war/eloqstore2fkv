# කාර්ය සාධනය

fkv ගබඩාවෙන් `perf-latest` හි `fkv_bench` බාගත කර ස්ථාවර යන්ත්‍රයක එම කාර්ය භාරය ක්‍රියාත්මක කරන්න.
ප්‍රතිදානය, ප්‍රමාද ප්‍රමාණ සහ උච්ච RSS C++ මූලික රේඛාවකට සංසන්දනය කරන්න.

පරාමිති මූලාශ්‍රය fkv සමඟ අනුකූල වේ:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

C++ මූලික රේඛාව ඔරකල් පරිසරය මගින් ක්‍රියාත්මක වේ `simple_bench` පසුව එම ක්‍රමයට අනුව ප්‍රතිදානය කර ප්‍රකාශයට පත් කෙරේ
`perf-baseline` වත්කම මුදා හරින්න. සංසන්දනාත්මක ප්රතිඵල නැවත ගබඩා ලේඛනයට ලියා ඇති අතර, වෙබ් අඩවිය සෘජුවම Markdown ලබා දෙයි.
JSON දත්ත ස්තරයක් නඩත්තු නොවේ.
