# 2026-11-06- ပင်မစာမျက်နှာ စွမ်းဆောင်ရည်ဇယား၊ အညွှန်းချဲ့ထွင်မှုနှင့် စာမျက်နှာများ

ယနေ့အပ်ဒိတ်သည် စွမ်းဆောင်ရည်သုံးသပ်ချက်များနှင့် ဆိုက်စတင်ခြင်းအပေါ် အာရုံစိုက်သည်။

## ပင်မစာမျက်နှာစွမ်းဆောင်ရည်နှိုင်းယှဉ်

- ပင်မစာမျက်နှာကို စွမ်းဆောင်ရည်ဦးစားပေးအဖြစ် ပြောင်းလဲလိုက်ပြီး C++/Rust နှိုင်းယှဉ်ဇယားကို ပထမစခရင်တွင် တိုက်ရိုက်ပြသထားသည်။
- ညွှန်ကိန်းအသစ်သုံးစုံကို ထည့်သွင်းထားသည်- ယုတ္တိတန်သော လှိုင်းနှုန်း၊ P99.9 အမြီးနှောင့်နှေးမှုနှင့် spatial ချဲ့ထွင်မှု။
- ထပ်ထည့်ထားသော Rust လည်ပတ်နေသောအသေးစိတ်အချက်များ- စကင်န်ဖတ်ခြင်း၊ Fullscan၊ ချဲ့ထွင်ရေးသားခြင်း၊ စနစ်ခေါ်ဆိုမှုအရေအတွက်နှင့် တစ်သုတ်လျှင် ဒေတာထပ်တူပြုခြင်း။
- `write-read` ရောစပ်ထားသော လုပ်ရည်ကိုင်ရည်အဖြစ် ပြတ်သားစွာ အမှတ်အသားပြုပြီး စွမ်းဆောင်ရည် စာရွက်စာတမ်းသို့ လင့်ခ်ချိတ်ပါ။

လက်ရှိ စက်တူအခြေခံလိုင်း-

| အညွှန်း | C++ | Rust | Rust / C++ |
|---|---:|---:|---:|
| Put | 16,866 kv/s | 21,377 kv/s | 1.27x |

| Get P99 | 31.2 ms | 10.0 ms | 0.32x |
| Put P99.9 | 86.0 ms | 223.3 ms | 2.60x |
| Get P99.9 | 48.2 ms | 355.5 ms | 7.37x |
| RSS အမြင့်ဆုံး | 175.6 MiB | 145.5 MiB | 0.83x |
| သိုလှောင်မှုအသုံးပြုမှု | 269.0 MiB | 101.4 MiB | 0.38x |

## အကဲဖြတ်ညွှန်းကိန်းများ

RocksDB၊ LevelDB၊ YCSB၊ WiredTiger နှင့် အခြားစံသတ်မှတ်ချက်များ ၏ ဘုံထွက်ရှိမှုကို ရည်ညွှန်း၍ ကျွန်ုပ်ထပ်ပြောသည်။

- ကျိုးကြောင်းဆီလျော်စွာ ဖတ်ရှုနိုင်၊ ရေးနိုင်သော bandwidth MiB/s;
- P99.9 အမြီးနှောင့်နှေးမှု;
- အာကာသချဲ့ထွင်ခြင်း၊ ချဲ့ထွင်ရေးသားခြင်း၊
- အသုတ်တစ်ခုစီတွင် စနစ်ခေါ်ဆိုမှုများနှင့် ဒေတာထပ်တူပြုခြင်းအရေအတွက်၊
- စကင်န် / Fullscan ဖြတ်သန်းမှု;
- CPU၊ စာမျက်နှာချို့ယွင်းချက်များ၊ ဆက်စပ်ခလုတ်များ နှင့် လုပ်ငန်းစဉ် IO တို့ကို အရင်းအမြစ် sidecar မှ ဆက်လက်စုဆောင်းနေပါသည်။

တစ်ချိန်တည်း`gxhash_4096B_gib_s` အငြိမ်းစားယူသည်။ ၎င်းသည် KV အင်ဂျင်လမ်းကြောင်းတွင်မရှိသော 4 KiB single block hash microbenchmark တစ်ခုဖြစ်သည်။

## မှန်ကန်မှုနှင့် အင်ဂျင်နီယာဆိုင်ရာ ပြင်ဆင်မှုများ

- `--rng cpp`ဖတ်ရန်/စကင်န်၏ သော့နေရာကို ပြင်ပါ- ဖတ်ရန် ထောက်လှမ်းမှုကို `key_interval`ဖြင့် မမြှောက်တော့ဘဲ ဖတ်ရှုခြင်း၏ 75% ကို မရေးထားသော သော့များထဲသို့ ကျသွားခြင်းမှ ရှောင်ကြဉ်ပါ။
- macOS `openrsync` တူညီသောအကြောင်းအရာဖြင့် manifests များကို လွဲမှားစွာ အမှားအယွင်းဖြစ်စေသော macOS မှ ပြန်စဥ်းစားမှုများကို ပြင်ဆင်ထားသည်။
- QEMU virtual disks များကို local SSDs များအဖြစ် အထင်လွဲမှားမိသည့် hardware gate ပြဿနာကို ဖြေရှင်းခဲ့သည်။
