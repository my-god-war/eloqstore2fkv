# စွမ်းဆောင်ရည်

fkv repository မှ `perf-latest` ၏ `perf-latest`ကို ဒေါင်းလုဒ်လုပ်ကာ ပုံသေစက်ပေါ်တွင် တူညီသောအလုပ်ပမာဏကို လုပ်ဆောင်ပါ။
ပြီးလျှင် ဖြတ်သန်းမှု၊ တုံ့ပြန်မှုပမာဏနှင့် အမြင့်ဆုံး RSS ကို C++ အခြေခံလိုင်းတစ်ခုနှင့် နှိုင်းယှဉ်ပါ။

ကန့်သတ်အရင်းအမြစ်သည် fkv နှင့် ကိုက်ညီသည်-

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

C++ အခြေခံလိုင်းကို oracle ပတ်၀န်းကျင် `simple_bench`ဖြင့် လုပ်ဆောင်ပြီး တူညီသော schema အရ ထုတ်ပေးပြီး ထုတ်ဝေရန်၊
`perf-baseline` ပိုင်ဆိုင်မှုကို ထုတ်လွှတ်ပါ။ နှိုင်းယှဉ်မှုရလဒ်များကို သိုလှောင်ရုံစာရွက်စာတမ်းသို့ ပြန်လည်ရေးသားထားပြီး ဆိုက်သည် Markdown ကို တိုက်ရိုက်ပြန်ဆိုသည်။
JSON ဒေတာအလွှာကို ထိန်းသိမ်းထားခြင်းမရှိပါ။
