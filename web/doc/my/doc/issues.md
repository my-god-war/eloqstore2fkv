# မှတ်တမ်းများကို ပြန်လည်သုံးသပ်ပါ။

`issue/` သည် ပြောင်းရွှေ့မှုအတွင်း သုံးသပ်ချက်ဘုတ်ဖြစ်ပါသည်-

- `new/`- မှတ်ချက်အသစ်များအတွက် ထည့်သွင်းပါ။
- `todo/`- လက်ခံထားပြီး၊ ဆိုင်းငံ့ထားသော ဖွံ့ဖြိုးတိုးတက်မှု။
- `done/`- တီထွင်ပြီး စမ်းသပ်မှု အထောက်အထားများ ပါရှိပြီး ဆိုင်းငံ့ထားသည့် ပြန်လည်သုံးသပ်ခြင်း။
- `reviewed/`- မှတ်တမ်းကို ပြန်လည်သုံးသပ်ပြီးပါပြီ။
- `reject/`- မွေးစားခြင်းမပြုပါက ကျေးဇူးပြု၍ အကြောင်းပြချက်များကို ဖော်ပြပါ။

လုပ်ငန်းစဉ်အတွက် `issue/new.md`၊ `issue/run.md`၊ `issue/review.md`ကို ကြည့်ပါ။

ပြန်လည်သုံးသပ်ချက်သည် fkv နှင့် C++ အကောင်အထည်ဖော်မှုများကြားတွင် အပြုအမူဆိုင်ရာ ကွဲပြားမှုများ၊ ဖော်မက်သဟဇာတဖြစ်မှု၊ စွမ်းဆောင်ရည်နှင့် ကုဒ်ဖွဲ့စည်းပုံတို့ကို အလေးပေးထားသည်။ ထင်မြင်ချက်တစ်ခု
အစုလိုက်ရွှေ့ခြင်းကို ရှောင်ရှားရန် ဖိုင်များ။
