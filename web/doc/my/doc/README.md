# eloqstore2fkv

eloqstore မှ fkv သို့ ရွှေ့ပြောင်းခြင်းနှင့် လိုက်ဖက်ညီသော စိစစ်ရေးဂိုဒေါင်။

ပင်မ fkv repository သည် သန့်စင်သော Rust ရှိပြီး သီးခြားတည်ဆောက်ထားသည်။ ဤသိုလှောင်မှုတွင် C++ ရည်ညွှန်းအကောင်အထည်ဖော်မှု oracle၊ bidirectional byte corpus ကို ထိန်းသိမ်းထားသည်။
စာရင်းဇယားများ၊ သမိုင်းဆိုင်ရာ စာရင်းစစ်မှတ်တမ်းများကို ရွှေ့ပြောင်းပြီး CI ကို စစ်ဆေးပါ။

## အကြောင်းအရာ

- C++ oracle- eloqstore ဖော်မတ်အလွှာကို လင့်ခ်ချိတ်ပြီး စာမျက်နှာ/အညွှန်း/ပိုလျှံ/မန်နီးဖက်စ်/ကို ဖန်တီးပါ။
  compress corpus ။
- Bidirectional corpus- C++ write → Rust read ၊ Rust write → C++ read
- `fkv_compat`- fkv ဂိုဒေါင်၏ ဖော်မတ်သေတ္တာအပေါ် မူတည်၍ Rust-side compatibility test
- `fkv_ledger`- eloqstore ကို စကင်န်ဖတ်ပါ၊ ရွှေ့ပြောင်းခြင်းဆိုင်ရာ လယ်ဂျာကို မှတ်တမ်းတင်ပါ၊ corpus ကို ထုတ်လုပ်ပြီး အတည်ပြုပါ။
- စွမ်းဆောင်ရည် နှိုင်းယှဉ်ချက်- တူညီသော အလုပ်ပမာဏအောက်တွင် fkv နှင့် C++ အခြေခံလိုင်းများကို နှိုင်းယှဉ်ပါ။
