# Revisar registres

`issue/` és el tauler de revisió durant la migració:

- `new/`: entrada per a comentaris nous.
- `todo/`: Aprovat, pendent de desenvolupament.
- `done/`: desenvolupat i té proves de prova, pendent de revisió.
- `reviewed/`: s'ha revisat l'arxiu.
- `reject/`: si no s'adopta, indiqueu-ne els motius.

Consulteu `issue/new.md`, `issue/run.md`, `issue/review.md` per conèixer el procés.

La revisió se centra en les diferències de comportament, la compatibilitat de formats, el rendiment i l'estructura del codi entre les implementacions fkv i C++. Una opinió per
fitxers per evitar moviments massius.
