# Ir-reġistri tar-reviżjoni

`issue/` huwa l-bord ta' reviżjoni waqt il-migrazzjoni:

- `new/`: Dħul għal kummenti ġodda.
- `todo/`: Adottata, pendenti għall-iżvilupp.
- `done/`: Żviluppat u għandu evidenza tat-test, pendenti reviżjoni.
- `reviewed/`: Arkivju rivedut.
- `reject/`: Jekk mhux adottat, jekk jogħġbok agħti r-raġunijiet.

Ara `issue/new.md`, `issue/run.md`, `issue/review.md` għall-proċess.

Ir-reviżjoni tiffoka fuq differenzi fl-imġieba, il-kompatibilità tal-format, il-prestazzjoni, u l-istruttura tal-kodiċi bejn l-implimentazzjonijiet fkv u C++. Opinjoni waħda għal kull
fajls biex jiġu evitati movimenti bl-ingrossa.
