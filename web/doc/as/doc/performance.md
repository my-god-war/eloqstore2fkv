# কাৰ্যক্ষমতা

fkv ভঁৰালৰ পৰা `perf-latest` ৰ `perf-latest` ডাউনলোড কৰক আৰু একেটা কাৰ্য্যভাৰ এটা স্থিৰ যন্ত্ৰত চলাওক ।
আৰু থ্ৰুপুট, লেটেন্সি কোৱাণ্টাইল, আৰু শীৰ্ষ RSSক এটা C++ ভিত্তিৰেখাৰ সৈতে তুলনা কৰক।

প্ৰাচল উৎস fkv ৰ সৈতে সামঞ্জস্যপূৰ্ণ:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

C++ ভিত্তিৰেখা oracle পৰিৱেশ `simple_bench` দ্বাৰা পৰিচালিত হয় আৰু তাৰ পিছত একে আঁচনি অনুসৰি আউটপুট আৰু প্ৰকাশ কৰা হয়
`perf-baseline` সম্পত্তি মুকলি কৰক। তুলনাৰ ফলাফলসমূহ গুদাম নথিপত্ৰলৈ পুনৰ লিখা হয়, আৰু চাইটে প্ৰত্যক্ষভাৱে মাৰ্কডাউন ৰেণ্ডাৰ কৰে।
কোনো JSON তথ্য স্তৰ ৰক্ষণাবেক্ষণ কৰা হোৱা নাই।
