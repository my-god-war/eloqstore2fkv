# eloqstore2fkv

eloqstore ৰ পৰা fkv লৈ প্ৰব্ৰজন আৰু সুসংগততা পৰীক্ষণ গুদাম।

মূল fkv ভঁৰাল বিশুদ্ধ Rust হৈ থাকে আৰু স্বতন্ত্ৰভাৱে নিৰ্মাণ কৰা হয়; এই ভঁৰালে C++ প্ৰসংগ প্ৰণয়ন oracle, দ্বিমুখী বাইট কৰ্পাছ,
লেজাৰ, ঐতিহাসিক অডিট ৰেকৰ্ডসমূহ প্ৰব্ৰজন কৰা আৰু চিআই পৰীক্ষা কৰা।

## বিষয়

- C++ oracle: eloqstore বিন্যাস স্তৰ সংযোগ কৰক আৰু পৃষ্ঠা/সূচী/অভাৰফ্ল'/মেনিফেষ্ট/ সৃষ্টি কৰক
  কৰ্পাছ কম্প্ৰেছ কৰক।
- দ্বিমুখী কৰ্পাছ: C++ লিখা → মৰিছা পঢ়া, মৰিছা লিখা → C++ পঢ়া।
- `fkv_compat`: মৰিছা-পক্ষৰ সুসংগততা পৰীক্ষা, fkv গুদামৰ বিন্যাস ক্ৰেটৰ ওপৰত নিৰ্ভৰ কৰি।
- `fkv_ledger`: eloqstore স্কেন কৰক, প্ৰব্ৰজন লেজাৰ ৰেকৰ্ড কৰক, কৰ্পাছ সৃষ্টি আৰু পৰীক্ষা কৰক।
- পৰিৱেশন তুলনা: একেটা কাৰ্য্যভাৰৰ অধীনত fkv আৰু C++ ভিত্তিৰেখা তুলনা কৰক।
