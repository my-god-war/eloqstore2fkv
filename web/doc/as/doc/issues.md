# ৰেকৰ্ডসমূহ পৰ্যালোচনা কৰক

`issue/` হৈছে প্ৰব্ৰজনৰ সময়ত পৰ্যালোচনা ব'ৰ্ড:

- `new/`: নতুন মন্তব্যৰ বাবে প্ৰৱেশ।
- `todo/`: গ্ৰহণ কৰা হৈছে, উন্নয়নৰ অপেক্ষাত।
- `done/`: বিকশিত আৰু পৰীক্ষাৰ প্ৰমাণ আছে, পৰ্যালোচনাৰ অপেক্ষাত।
- `reviewed/`: আৰ্কাইভ পৰ্যালোচনা কৰা হৈছে।
- `reject/`: যদি গ্ৰহণ কৰা হোৱা নাই, তেন্তে কাৰণসমূহ উল্লেখ কৰক।

প্ৰক্ৰিয়াৰ বাবে `issue/new.md`, `issue/run.md`, `issue/review.md` চাওক।

পৰ্যালোচনাই আচৰণৰ পাৰ্থক্য, বিন্যাস সুসংগততা, পৰিৱেশন, আৰু fkv আৰু C++ প্ৰণয়নৰ মাজত ক'ড গঠনত গুৰুত্ব দিয়ে। প্ৰতি এটা মতামত
বাল্ক স্থানান্তৰ এৰাই চলিবলৈ ফাইলসমূহ।
