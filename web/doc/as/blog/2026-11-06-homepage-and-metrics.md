# ২০২৬-১১-০৬: হোম পেজৰ পৰিৱেশন টেবুল, সূচক সম্প্ৰসাৰণ আৰু পৃষ্ঠাসমূহ

আজিৰ আপডেটটোৱে পৰিৱেশন পৰ্যালোচনা আৰু চাইট মুকলিৰ ওপৰত গুৰুত্ব আৰোপ কৰে।

## হোম পেজৰ পৰিৱেশন তুলনা

- হোমপেজক পৰিৱেশন অগ্ৰাধিকাৰলৈ সলনি কৰা হয়, আৰু C++/Rust তুলনা টেবুল প্ৰত্যক্ষভাৱে প্ৰথম পৰ্দাত প্ৰদৰ্শিত হয়।
- সূচকৰ তিনিটা নতুন গোট যোগ কৰা হৈছে: লজিকেল বেণ্ডউইডথ, P99.9 টেইল ডিলে, আৰু স্থানীয় পৰিবৰ্ধন।
- যোগ কৰা হৈছে Rust চলি থকা বিৱৰণ: স্কেন, ফুলস্কেন, লিখা পৰিবৰ্ধন, লিখা চিস্টেম কলৰ সংখ্যা আৰু প্ৰতিটো বেচত তথ্য সমন্বয়।
- `write-read`ক মিশ্ৰিত কেলিবাৰ হিচাপে স্পষ্টভাৱে চিহ্নিত কৰক আৰু পৰিৱেশন আলেখ্যনৰ সৈতে সংযোগ কৰক।

বৰ্তমানৰ একে-মেচিনৰ ভিত্তিৰেখা:

| সূচী | C++ | Rust | Rust / C++ |
|---|---:|---:|---:|
| Put | 16,866 kv/s | 21,377 kv/s | 1.27x |
| Get | 5,526 QPS | 7,293 QPS | 1.32x |
| Put P99 | 51.2 ms | 35.1 ms | 0.69x |
| Get P99 | 31.2 ms | 10.0 ms | 0.32x |
| Put P99.9 | 86.0 ms | 223.3 ms | 2.60x |
| Get P99.9 | 48.2 ms | 355.5 ms | 7.37x |
| শিখৰ আৰ এছ এছ | 175.6 MiB | 145.5 MiB | 0.83x |
| সংৰক্ষণৰ ব্যৱহাৰ | 269.0 MiB | 101.4 MiB | 0.38x |

## মূল্যায়ন সূচক

RocksDB, LevelDB, YCSB, WiredTiger আৰু অন্যান্য বেঞ্চমাৰ্কসমূহৰ সাধাৰণ আউটপুটৰ উল্লেখ কৰি, মই যোগ কৰিলোঁ:

- লজিকেল পঢ়া আৰু লিখা বেণ্ডউইডথ MiB/s;
- P99.9 ঠেং বিলম্ব;
- মহাকাশ পৰিবৰ্ধন, লিখাৰ পৰিবৰ্ধন;
- প্ৰতিটো বেচত ৰাইট চিস্টেম কলৰ সংখ্যা আৰু ডাটা সমন্বয়;
- স্কেন / ফুলস্কেন থ্ৰুপুট;
- CPU, পৃষ্ঠাৰ ত্ৰুটিসমূহ, প্ৰসংগ চুইচসমূহ, আৰু প্ৰক্ৰিয়া IO সম্পদ sidecar দ্বাৰা সংগ্ৰহ কৰা হয়।

একে সময়তে অৱসৰ গ্ৰহণ`gxhash_4096B_gib_s`। ই এটা 4 KiB একক ব্লক হেচ মাইক্ৰ'বেঞ্চমাৰ্ক যি KV ইঞ্জিন পথত নাই আৰু ইয়াৰ কোনো C++ সমকক্ষ নাই।

## শুদ্ধতা আৰু অভিযান্ত্ৰিক সমাধান

- `--rng cpp` পঢ়া/স্কেনৰ চাবিৰ স্থান ঠিক কৰক: পঢ়া ধৰা পেলোৱাক আৰু `key_interval` ৰে গুণ কৰা নহয় যাতে ৭৫% পঢ়াসমূহ অলিখিত কি'সমূহত পৰাৰ পৰা হাত সাৰিব পাৰি।
- macOS `openrsync` একে বিষয়বস্তুৰ সৈতে মেনিফেষ্টৰ ভুল বিচাৰৰ ফলত হোৱা ষ্টেণ্ডবাই পুনৰ চেষ্টা ঠিক কৰা হৈছে।
- এটা হাৰ্ডৱেৰ গেট সমস্যা সমাধান কৰা হৈছে য'ত QEMU ভাৰ্চুৱেল ডিষ্কসমূহক স্থানীয় SSDs হিচাপে ভুল বিচাৰ কৰা হৈছিল।
