# Migrate ledger

`tool/fkv_ledger` Use tree-sitter to scan eloqstore, map and verify C++ symbols and fkv
Evidence is written to motedb.

```bash
cargo run -p fkv_ledger -- sync
cargo run -p fkv_ledger -- next --limit 20
cargo run -p fkv_ledger -- stats
cargo run -p fkv_ledger -- changed --check
cargo run -p fkv_ledger -- report --out doc/progress.md
```

The ledger database is at `.data/motedb.mote` and is not stored in the database.

`verified` must have pass evidence; `doc/progress.md` is generated by `report`.
