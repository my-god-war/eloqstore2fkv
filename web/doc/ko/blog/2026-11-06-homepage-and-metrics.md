# 2026-11-06: 홈페이지 실적표, 지표 확장 및 페이지

오늘의 업데이트는 성능 검토 및 사이트 출시에 중점을 두고 있습니다.

## 홈페이지 성능 비교

- 홈페이지가 성능우선순위로 바뀌고 첫화면에 C++/Rust 비교표가 바로 나옵니다.
- 논리 대역폭, P99.9 테일 지연 및 공간 증폭이라는 세 가지 새로운 표시기 세트가 추가되었습니다.
- Rust 실행 세부 정보가 추가되었습니다: 스캔, 전체 스캔, 쓰기 증폭, 쓰기 시스템 호출 수 및 배치당 데이터 동기화.
- `write-read`을 혼합 구경으로 명시적으로 표시하고 성능 문서에 대한 링크를 연결합니다.

현재 동일 머신 기준:

| 색인 | C++ | Rust | Rust / C++ |
|---|---:|---:|---:|
| Put | 16,866 kv/s | 21,377 kv/s | 1.27x |
| Get | 5,526 QPS | 7,293 QPS | 1.32x |
| Put P99 | 51.2 ms | 35.1 ms | 0.69x |
| Get P99 | 31.2 ms | 10.0 ms | 0.32x |
| Put P99.9 | 86.0 ms | 223.3 ms | 2.60x |
| Get P99.9 | 48.2 ms | 355.5 ms | 7.37x |
| 피크 RSS | 175.6 MiB | 145.5 MiB | 0.83x |
| 스토리지 사용량 | 269.0 MiB | 101.4 MiB | 0.38x |

## 평가지표

RocksDB, LevelDB, YCSB, WiredTiger 및 기타 벤치마크의 공통 결과를 참조하여 다음을 추가했습니다.

- 논리적 읽기 및 쓰기 대역폭 MiB/s;
- P99.9 테일 지연;
- 공간 증폭, 쓰기 증폭;
- 각 배치의 쓰기 시스템 호출 및 데이터 동기화 수입니다.
- 스캔/전체 스캔 처리량;
- CPU, 페이지 오류, 컨텍스트 스위치 및 프로세스 IO는 리소스 사이드카에 의해 계속 수집됩니다.

동시에 은퇴했습니다`gxhash_4096B_gib_s`. 이는 KV 엔진 경로에 없고 C++ 대응 항목이 없는 4KiB 단일 블록 해시 마이크로벤치마크입니다.

## 정확성 및 엔지니어링 수정

- `--rng cpp` 읽기/스캔의 키 공간을 수정합니다. 읽기의 75%가 작성되지 않은 키에 해당하는 것을 방지하기 위해 읽기 감지에 더 이상 `key_interval`를 곱하지 않습니다.
- macOS `openrsync` 동일한 콘텐츠가 포함된 매니페스트를 잘못 판단하여 발생한 대기 재시도 문제를 수정했습니다.
- QEMU 가상 디스크가 로컬 SSD로 잘못 판단되는 하드웨어 게이트 문제를 수정했습니다.

## 사이트 및 게시

- GitHub 페이지 활성화됨: <https://my-god-war.github.io/eloqstore2fkv/>
- 사이트 라우팅은 `/eloqstore2fkv/` 하위 경로를 지원합니다.
- 대신 `raw.githubusercontent.com`에서 문서를 읽고 jsDelivr 경로에 `web/`가 누락되어 발생하는 404가 수정되었습니다.
- 블로그 탐색 및 `bun run tran` 다국어 번역이 통합되었습니다. 이 기사는 중국어 소스에서 다른 언어로 자동 번역됩니다.
