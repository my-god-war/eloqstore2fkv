# 기록 검토

`issue/`은 마이그레이션 중 검토 게시판입니다.

- `new/`: 새 댓글 항목입니다.
- `todo/`: 채택, 개발 대기 중.
- `done/`: 개발되었으며 테스트 증거가 있으며 검토 대기 중입니다.
- `reviewed/`: 아카이브가 검토되었습니다.
- `reject/`: 채택되지 않은 경우 그 이유를 명시해 주십시오.

프로세스는 `issue/new.md`, `issue/run.md`, `issue/review.md`를 참조하세요.

검토에서는 fkv와 C++ 구현 간의 동작 차이점, 형식 호환성, 성능 및 코드 구조에 중점을 둡니다. 하나의 의견
대량 이동을 방지하기 위한 파일입니다.
