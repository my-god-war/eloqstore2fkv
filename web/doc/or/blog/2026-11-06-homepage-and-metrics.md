# 2026-11-06: ମୂଳପୃଷ୍ଠା କାର୍ଯ୍ୟଦକ୍ଷତା ସାରଣୀ, ସୂଚକ ବିସ୍ତାର ଏବଂ ପୃଷ୍ଠାଗୁଡ଼ିକ |

ଆଜିର ଅଦ୍ୟତନ କାର୍ଯ୍ୟଦକ୍ଷତା ସମୀକ୍ଷା ଏବଂ ସାଇଟ୍ ଲଞ୍ଚ ଉପରେ ଧ୍ୟାନ ଦେଇଥାଏ |

## ମୂଳପୃଷ୍ଠା କାର୍ଯ୍ୟଦକ୍ଷତା ତୁଳନା

- ମୂଳପୃଷ୍ଠାକୁ କାର୍ଯ୍ୟଦକ୍ଷତା ପ୍ରାଥମିକତାକୁ ବଦଳାଯାଇଥାଏ, ଏବଂ C ++ / ରୁଷ୍ଟ ତୁଳନା ଟେବୁଲ୍ ପ୍ରଥମ ପରଦାରେ ସିଧାସଳଖ ପ୍ରଦର୍ଶିତ ହୁଏ |
- ତିନୋଟି ନୂତନ ସୂଚକ ସେଟ୍ ଯୋଡା ଯାଇଛି: ଲଜିକାଲ୍ ବ୍ୟାଣ୍ଡୱିଡଥ୍, P99.9 ଲାଞ୍ଜ ବିଳମ୍ବ, ଏବଂ ସ୍ଥାନିକ ବିସ୍ତାର |
- ରୁଷ୍ଟ ଚାଲୁଥିବା ବିବରଣୀଗୁଡିକ ଯୋଡାଗଲା: ସ୍କାନ୍, ଫୁଲ୍ସ୍କାନ୍, ଲେଖିବା ଏମ୍ପ୍ଲାଇଫେସନ୍, ଲେଖିବା ସିଷ୍ଟମ୍ କଲ୍ ସଂଖ୍ୟା ଏବଂ ବ୍ୟାଚ୍ ପ୍ରତି ଡାଟା ସିଙ୍କ୍ରୋନାଇଜେସନ୍ |
- ସ୍ପଷ୍ଟ ଭାବରେ `write-read` କୁ ମିଶ୍ରିତ କ୍ୟାଲେବର୍ ଭାବରେ ଚିହ୍ନିତ କରନ୍ତୁ ଏବଂ କାର୍ଯ୍ୟଦକ୍ଷତା ଡକ୍ୟୁମେଣ୍ଟେସନ୍ ସହିତ ଲିଙ୍କ୍ କରନ୍ତୁ |

ସାମ୍ପ୍ରତିକ ସମାନ ମେସିନ୍ ବେସ୍ ଲାଇନ୍:

|---|---:|---:|---:|

| Get | 5,526 QPS | 7,293 QPS | 1.32x |
| Put P99 | 51.2 ms | 35.1 ms | 0.69x |
| Get P99 | 31.2 ms | 10.0 ms | 0.32x |
| Put P99.9 | 86.0 ms | 223.3 ms | 2.60x |
| Get P99.9 | 48.2 ms | 355.5 ms | 7.37x |
| ଶିଖର RSS | 175.6 MiB | 145.5 MiB | 0.83x |

## ମୂଲ୍ୟାଙ୍କନ ସୂଚକ

RocksDB, LevelDB, YCSB, WiredTiger ଏବଂ ଅନ୍ୟାନ୍ୟ ମାନଦଣ୍ଡର ସାଧାରଣ ଫଳାଫଳକୁ ଅନୁସରଣ କରି ମୁଁ ଯୋଗ କଲି:

- ଯୁକ୍ତିଯୁକ୍ତ ପ read ଼ିବା ଏବଂ ବ୍ୟାଣ୍ଡୱିଡଥ୍ MiB / s ଲେଖିବା;
- P99.9 ଲାଞ୍ଜ ବିଳମ୍ବ;
- ସ୍ପେସ୍ ଏମ୍ପ୍ଲାଇଫେସନ୍, ଲେଖିବା ଏମ୍ପ୍ଲାଇଫେସନ୍;
- ପ୍ରତ୍ୟେକ ବ୍ୟାଚ୍ ରେ ଲେଖା ସିଷ୍ଟମ୍ କଲ୍ ଏବଂ ଡାଟା ସିଙ୍କ୍ରୋନାଇଜେସନ୍ ସଂଖ୍ୟା;
- ସ୍କାନ୍ / ଫୁଲ୍ସ୍କାନ୍ ଥ୍ରୋପପୁଟ୍;
- CPU, ପୃଷ୍ଠା ତ୍ରୁଟି, ପ୍ରସଙ୍ଗ ସୁଇଚ୍, ଏବଂ ପ୍ରକ୍ରିୟା IO ଉତ୍ସ ସାଇଡେକାର୍ ଦ୍ୱାରା ସଂଗୃହିତ ହୋଇ ରହିଥାଏ |

ଏକ ସମୟରେ ଅବସରପ୍ରାପ୍ତ `gxhash_4096B_gib_s` | ଏହା ଏକ 4 KiB ଏକକ ବ୍ଲକ୍ ହ୍ୟାସ୍ ମାଇକ୍ରୋବେଞ୍ଚମାର୍କ ଯାହା KV ଇଞ୍ଜିନ୍ ପଥରେ ନାହିଁ ଏବଂ ଏହାର C ++ ପ୍ରତିପକ୍ଷ ନାହିଁ |

## ସଠିକତା ଏବଂ ଇଞ୍ଜିନିୟରିଂ ଫିକ୍ସ |

- `--rng cpp` ର ପ space ଼ିବା / ସ୍କାନର ମୁଖ୍ୟ ସ୍ଥାନକୁ ଠିକ କରନ୍ତୁ: ପ read ଼ୁଥିବା ଚିହ୍ନଟକୁ ଆଉ `key_interval` ଦ୍ୱାରା ଲିଖିତ ଚାବିରେ ପଡ଼ିବା ପାଇଁ 75% ପ read ଼ିବା ପାଇଁ ବ multip ଼ାଯାଏ ନାହିଁ |
