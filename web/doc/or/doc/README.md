# eloqstore2fkv

ଏଲୋକ୍ଷ୍ଟୋରରୁ fkv ପର୍ଯ୍ୟନ୍ତ ସ୍ଥାନାନ୍ତରଣ ଏବଂ ସୁସଙ୍ଗତତା ଯାଞ୍ଚ ଗୋଦାମ |

ମୁଖ୍ୟ fkv ସଂଗ୍ରହାଳୟ ଶୁଦ୍ଧ ରୁଷ୍ଟ ରହିଥାଏ ଏବଂ ସ୍ୱାଧୀନ ଭାବରେ ନିର୍ମିତ; ଏହି ସଂଗ୍ରହାଳୟ C ++ ରେଫରେନ୍ସ ପ୍ରୟୋଗ oracle, ଦ୍ୱି-ଦିଗୀୟ ବାଇଟ୍ କର୍ପସ୍,
ଲିଜର୍, historical ତିହାସିକ ଅଡିଟ୍ ରେକର୍ଡ ସ୍ଥାନାନ୍ତର କରନ୍ତୁ ଏବଂ CI ଯାଞ୍ଚ କରନ୍ତୁ |

## ବିଷୟବସ୍ତୁ

- C ++ oracle: eloqstore ଫର୍ମାଟ୍ ସ୍ତରକୁ ଲିଙ୍କ୍ କରନ୍ତୁ ଏବଂ ପୃଷ୍ଠା / ଇଣ୍ଡେକ୍ସ / ଓଭରଫ୍ଲୋ / ମନିଫେଷ୍ଟ୍ / ସୃଷ୍ଟି କରନ୍ତୁ |
  କର୍ପସକୁ ସଙ୍କୋଚନ କରନ୍ତୁ |
- ଦ୍ୱି-ଦିଗୀୟ କର୍ପସ୍: C ++ ଲେଖ → ରୁଷ୍ଟ ପ read, ରୁଷ୍ଟ ଲେଖ → C ++ ପ read |
- `fkv_compat`: fkv ଗୋଦାମର ଫର୍ମାଟ୍ କ୍ରେଟ୍ ଉପରେ ନିର୍ଭର କରି ରୁଷ୍ଟ-ପାର୍ଶ୍ୱ ସୁସଙ୍ଗତତା ପରୀକ୍ଷା |
- `fkv_ledger`: ଏଲୋକ୍ଷ୍ଟୋର ସ୍କାନ୍ କରନ୍ତୁ, ସ୍ଥାନାନ୍ତରଣ ଲିଜର୍ ରେକର୍ଡ କରନ୍ତୁ, କର୍ପସ୍ ସୃଷ୍ଟି ଏବଂ ଯାଞ୍ଚ କରନ୍ତୁ |
- କାର୍ଯ୍ୟଦକ୍ଷତା ତୁଳନା: ସମାନ କାର୍ଯ୍ୟଭାରରେ fkv ଏବଂ C ++ ବେସଲାଇନ୍ ତୁଳନା କରନ୍ତୁ |
