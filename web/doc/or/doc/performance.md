# କାର୍ଯ୍ୟଦକ୍ଷତା

Fkv ରେପୋଜିଟୋରୀରୁ `fkv_bench` ର `perf-latest` ଡାଉନଲୋଡ୍ କରନ୍ତୁ ଏବଂ ଏକ ନିର୍ଦ୍ଦିଷ୍ଟ ଯନ୍ତ୍ରରେ ସମାନ କାର୍ଯ୍ୟ ଭାର ଚଲାନ୍ତୁ |
ଏବଂ ଥ୍ରୋପପୁଟ୍, ବିଳମ୍ବତା ପରିମାଣ, ଏବଂ ଶିଖର RSS କୁ ଏକ C ++ ବେସ୍ ଲାଇନ୍ ସହିତ ତୁଳନା କରନ୍ତୁ |

ପାରାମିଟର ଉତ୍ସ fkv ସହିତ ସମାନ ଅଟେ:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

C ++ ବେସଲାଇନ୍ oracle ପରିବେଶ `simple_bench` ଦ୍ୱାରା ପରିଚାଳିତ ଏବଂ ତାପରେ ସମାନ ସ୍କିମା ଅନୁଯାୟୀ ଆଉଟପୁଟ୍ ଏବଂ ପ୍ରକାଶିତ |
`perf-baseline` ରିଲିଜ୍ ସମ୍ପତ୍ତି | ତୁଳନାତ୍ମକ ଫଳାଫଳଗୁଡିକ ଗୋଦାମ ଡକ୍ୟୁମେଣ୍ଟକୁ ପୁନ written ଲେଖାଯାଇଛି, ଏବଂ ସାଇଟ୍ ସିଧାସଳଖ ମାର୍କଡାଉନ୍ ପ୍ରଦାନ କରେ |
କ J ଣସି JSON ଡାଟା ସ୍ତର ରକ୍ଷଣାବେକ୍ଷଣ କରାଯାଏ ନାହିଁ |
