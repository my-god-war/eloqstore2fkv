# ରେକର୍ଡଗୁଡିକ ସମୀକ୍ଷା କରନ୍ତୁ |

ସ୍ଥାନାନ୍ତରଣ ସମୟରେ `issue/` ହେଉଛି ସମୀକ୍ଷା ବୋର୍ଡ:

- `new/`: ନୂତନ ମନ୍ତବ୍ୟ ପାଇଁ ପ୍ରବେଶ |
- `todo/`: ଗ୍ରହଣ, ବିକାଶ ବିଚାରାଧୀନ |
- `done/`: ବିକଶିତ ଏବଂ ପରୀକ୍ଷଣ ପ୍ରମାଣ ଅଛି, ସମୀକ୍ଷା ବିଚାରାଧୀନ ଅଛି |
- `reviewed/`: ଅଭିଲେଖାଗାର ସମୀକ୍ଷା କରାଯାଇଛି |
- `reject/`: ଯଦି ଗ୍ରହଣ କରାଯାଇ ନାହିଁ, ଦୟାକରି ଏହାର କାରଣ ଦର୍ଶାନ୍ତୁ |

ପ୍ରକ୍ରିୟା ପାଇଁ `issue/new.md`, `issue/run.md`, `issue/review.md` ଦେଖନ୍ତୁ |

ସମୀକ୍ଷା fkv ଏବଂ C ++ ପ୍ରୟୋଗଗୁଡ଼ିକ ମଧ୍ୟରେ ଆଚରଣଗତ ପାର୍ଥକ୍ୟ, ଫର୍ମାଟ୍ ସୁସଙ୍ଗତତା, କାର୍ଯ୍ୟଦକ୍ଷତା, ଏବଂ କୋଡ୍ ଗଠନ ଉପରେ ଧ୍ୟାନ ଦେଇଥାଏ | ପ୍ରତି ଗୋଟିଏ ମତ
ବହୁଳ ଗତିକୁ ଏଡାଇବା ପାଇଁ ଫାଇଲଗୁଡିକ |
