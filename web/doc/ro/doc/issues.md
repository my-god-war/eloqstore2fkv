# Revizuiți înregistrările

`issue/` este comisia de examinare în timpul migrării:

- `new/`: intrare pentru comentarii noi.
- `todo/`: adoptat, în așteptarea dezvoltării.
- `done/`: dezvoltat și are dovezi de testare, în așteptarea examinării.
- `reviewed/`: arhiva revizuită.
- `reject/`: Dacă nu este adoptat, vă rugăm să precizați motivele.

Consultați `issue/new.md`, `issue/run.md`, `issue/review.md` pentru proces.

Revizuirea se concentrează pe diferențele de comportament, compatibilitatea formatelor, performanța și structura codului dintre implementările fkv și C++. O opinie per
fișiere pentru a evita mișcările în bloc.
