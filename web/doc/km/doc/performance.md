# ប្រសិទ្ធភាព

ទាញយក `perf-latest`នៃ `fkv_bench` ពីឃ្លាំង fkv ហើយដំណើរការបន្ទុកការងារដូចគ្នានៅលើម៉ាស៊ីនថេរ។
ហើយប្រៀបធៀបការឆ្លងកាត់ បរិមាណនៃភាពយឺតយ៉ាវ និងកំពូល RSS ទៅនឹង C++ baseline។

ប្រភពប៉ារ៉ាម៉ែត្រគឺស្របជាមួយ fkv៖

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

បន្ទាត់មូលដ្ឋាន C ++ ត្រូវបានដំណើរការដោយបរិស្ថាន oracle `simple_bench` ហើយបន្ទាប់មកចេញលទ្ធផលដោយយោងតាមគ្រោងការណ៍ដូចគ្នា និងបោះពុម្ពទៅ
`perf-baseline` បញ្ចេញទ្រព្យសកម្ម។ លទ្ធផលប្រៀបធៀបត្រូវបានសរសេរត្រឡប់ទៅឯកសារឃ្លាំង ហើយគេហទំព័រនេះបង្ហាញ Markdown ដោយផ្ទាល់។
មិនមានស្រទាប់ទិន្នន័យ JSON ត្រូវបានរក្សាទុកទេ។
