# eloqstore2fkv

ឃ្លាំងផ្ទៀងផ្ទាត់ចំណាកស្រុក និងភាពឆបគ្នាពី eloqstore ទៅ fkv ។

ឃ្លាំង fkv សំខាន់នៅតែជា Rust សុទ្ធ ហើយត្រូវបានសាងសង់ដោយឯករាជ្យ។ ឃ្លាំងនេះរក្សានូវ C ++ reference implementation oracle, bidirectional byte corpus,
ផ្លាស់ប្តូរបញ្ជីឈ្មោះ កំណត់ត្រាសវនកម្មប្រវត្តិសាស្ត្រ និងផ្ទៀងផ្ទាត់ CI ។

## មាតិកា

- C++ oracle៖ ភ្ជាប់ស្រទាប់ទ្រង់ទ្រាយ eloqstore និងបង្កើតទំព័រ/index/overflow/manifest/
  បង្ហាប់ corpus ។
- សាកសពទ្វេទិស៖ សរសេរ C ++ → អានច្រែះ សរសេរច្រែះ → C ++ អាន។
- `fkv_compat`៖ ការធ្វើតេស្តភាពឆបគ្នាខាងច្រែះ ដោយពឹងផ្អែកលើទម្រង់នៃឃ្លាំង fkv ។
- `fkv_ledger`៖ ស្កែន eloqstore, កត់ត្រាបញ្ជីឈ្មោះការធ្វើចំណាកស្រុក, បង្កើត និងផ្ទៀងផ្ទាត់សាកសព។
- ការប្រៀបធៀបការអនុវត្ត៖ ប្រៀបធៀបមូលដ្ឋាន fkv និង C ++ ក្រោមបន្ទុកការងារដូចគ្នា។
