# ពិនិត្យមើលកំណត់ត្រា

`issue/` គឺ​ជា​ក្រុមប្រឹក្សា​ពិនិត្យ​ក្នុង​ពេល​ធ្វើ​ចំណាក​ស្រុក៖

- `new/`៖ បញ្ចូល​មតិ​ថ្មី។
- `todo/`៖ បានអនុម័ត រង់ចាំការអភិវឌ្ឍន៍។
- `done/`៖ បង្កើត និង​មាន​ភស្តុតាង​សាកល្បង រង់ចាំ​ការ​ពិនិត្យ។
- `reviewed/`៖ បណ្ណសារត្រូវបានពិនិត្យ។
- `reject/`៖ បើ​មិន​បាន​អនុម័ត សូម​បញ្ជាក់​ពី​មូលហេតុ។

សូមមើល `issue/new.md`, `issue/run.md`, `issue/review.md` សម្រាប់ដំណើរការ។

ការពិនិត្យឡើងវិញផ្តោតលើភាពខុសគ្នានៃអាកប្បកិរិយា ភាពឆបគ្នានៃទម្រង់ ការអនុវត្ត និងរចនាសម្ព័ន្ធកូដរវាងការអនុវត្ត fkv និង C++ ។ មតិមួយសម្រាប់
ឯកសារដើម្បីជៀសវាងការផ្លាស់ទីច្រើន។
