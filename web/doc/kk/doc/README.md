# eloqstore2fkv

eloqstore-дан fkv-ге көшу және үйлесімділікті тексеру қоймасы.

Негізгі fkv репозиторийі таза Rust болып қалады және дербес құрастырылады; бұл репозиторий C++ анықтамалық іске асыру oracle, екі бағытты байт корпусын сақтайды,
Бухгалтерлік кітаптарды, тарихи аудит жазбаларын тасымалдаңыз және CI растаңыз.

## мазмұны

- C++ oracle: eloqstore пішім қабатын байланыстырыңыз және бет/индекс/толып кету/манифест/ жасаңыз
  корпусты қысу.
- Екі бағытты корпус: C++ жазу → Rust оқу, Rust жазу → C++ оқу.
- `fkv_compat`: fkv қоймасының пішім жәшігіне негізделген тот жағымен үйлесімділік сынағы.
- `fkv_ledger`: eloqstore сканерлеу, тасымалдау кітабын жазу, корпусты жасау және тексеру.
- Өнімділікті салыстыру: бірдей жұмыс жүктемесі кезінде fkv және C++ негізгі көрсеткіштерін салыстырыңыз.
