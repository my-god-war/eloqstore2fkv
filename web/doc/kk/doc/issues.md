# Жазбаларды қарап шығу

`issue/` - тасымалдау кезіндегі шолу тақтасы:

- `new/`: жаңа пікірлерге арналған жазба.
- `todo/`: Қабылданды, әзірлеуді күтуде.
- `done/`: Әзірленген және сынақ дәлелдері бар, тексеруді күтуде.
- `reviewed/`: Мұрағат қаралды.
- `reject/`: Егер қабылданбаса, себептерін көрсетіңіз.

Процесс үшін `issue/new.md`, `issue/run.md`, `issue/review.md` қараңыз.

Шолу мінез-құлық айырмашылықтарына, пішім үйлесімділігіне, өнімділікке және fkv және C++ іске асырулары арасындағы код құрылымына бағытталған. Бір пікір
файлдарды жаппай жылжытпау үшін.
