# Өнімділік

fkv репозиторийінен `fkv_bench` ішінен `perf-latest` жүктеп алыңыз және тұрақты құрылғыда бірдей жұмыс жүктемесін іске қосыңыз.
Өткізу қабілеттілігін, кідіріс квантильдерін және ең жоғары RSS-ті C++ базалық сызығымен салыстырыңыз.

Параметр көзі fkv мәніне сәйкес келеді:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

C++ негізін oracle ортасы `simple_bench` басқарады, содан кейін сол схемаға сәйкес шығарылады және келесіге жарияланады.
`perf-baseline` активті шығару. Салыстыру нәтижелері қойма құжатына қайта жазылады және сайт тікелей Markdown көрсетеді.
JSON деректер қабаты сақталмайды.

## Ағымдағы нәтижелер

2-схема негізгі 2026-11-06T04:25Z,`github-ubuntu-latest-x86_64`, 4 КБ бет,
`data_append_mode=false`, `direct_io=true`. Тұрақты жұмыс жүктемесі:
`rows/max_key=1000000`,`batch_size=100`,`write_batchs=10000`,
`read_per_part=4`,`partitions=1`,`kv_size=128`,`rng=cpp`
(`key_interval=4` / `del_ratio=4`), `test_secs=30`.

| жоба | C++ EloqStore | Rust fkv | Rust / C++ |
|---|---:|---:|---:|
| Өткізу қабілетін қойыңыз | 16,866 kv/s | 21,377 kv/s | 1.27x |
| Өткізу қабілеттілігін алыңыз | 5,526 QPS | 7,293 QPS | 1.32x |
| Логикалық өткізу қабілеттілігін қойыңыз | 2.06 MiB/s | 2.61 MiB/s | 1.27x |
| Логикалық өткізу қабілеттілігін алыңыз | 0.67 MiB/s | 0.89 MiB/s | 1.32x |
| Put P99 | 51.2 ms | 35.1 ms | 0.69x |
| Get P99 | 31.2 ms | 10.0 ms | 0.32x |
| Put P99.9 | 86.0 ms | 223.3 ms | 2.60x |
| Get P99.9 | 48.2 ms | 355.5 ms | 7.37x |
| Ең жоғары RSS | 175.6 MiB | 145.5 MiB | 0.83x |
| Жадты пайдалану | 269.0 MiB | 101.4 MiB | 0.38x |
| Сақтау / номиналды деректер | 2.20x | 0.83x | 0.38x |

1 миллион жазбаны жазу (10 000 партия) сәйкес келеді
`io_write_at_num=48,625`, `io_data_sync_num=10,000`, яғни деректер пакетке бір рет синхрондалады.
Тоттың қосымша көрсеткіштері: сканерлеу `141,166 kv/s`, толық сканерлеу `108,274 kv/s`, жазуды күшейту `2.57x`
(`proc_io_write` 329 МБ / 128 МБ логикалық жазулар), `4.86` бір пакетке жүйелік қоңырауларды жазу.
Сақтау коэффициенті 1М × 128В = 128 МБ номиналды деректер негізінде есептеледі; C++ бұл жолы GC/compact іске қоспайды,
Сондықтан ол тарихтың көбірек беттерін қамтиды. Бұл «өмір сүру деректер кеңістігін күшейту» сияқты калибрлі сан емес.
Rust-тың P99.9 кідірісі әлі де C++-тен нашар (86.0 мс-ке қарсы 223.3 мс, ал 355.5 мс-ке қарсы алыңыз)
48,2 мс), жалғыз базалық сызық қатты ауытқиды, егжей-тегжейлі ақпарат алу үшін ішкі perf есебін қараңыз.

**Ескертпе**: C++ `write-read` жазу ағыны мен оқу ағынының бір уақытта жұмыс істейтінін және қазіргі уақытта Rust екенін білдіреді.
«Жазуды аяқта, қайта аш, қайта оқы», оқу кезеңінде жазу сайысы жоқ. Сондықтан `write-read` көбейткіші ретінде қарастыруға болмайды
Таза оқу / таза жазу қорытынды; қатаң салыстыру үшін `scripts/perf_local.sh --symmetric` көру керек
Екі жұп нәтиже шығарылады: тек жазу және тек оқу үшін. Жалғыз ортақ жүгіруші нөмірлері тек регрессия үшін пайдаланылады
Трендтер, шығарылымдар `--runs` медианасының көмегімен бағаланады.
