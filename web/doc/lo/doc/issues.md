# ທົບທວນບັນທຶກ

`issue/` ແມ່ນຄະນະກວດກາໃນລະຫວ່າງການເຄື່ອນຍ້າຍ:

- `new/`: ປ້ອນຄຳເຫັນໃໝ່.
- `todo/`: ໄດ້ຮັບການຮັບຮອງເອົາ, ລໍຖ້າການພັດທະນາ.
- `done/`: ພັດທະນາ ແລະມີຫຼັກຖານການທົດສອບ, ລໍຖ້າການກວດສອບ.
- `reviewed/`: ກວດສອບແຟ້ມຈັດເກັບແລ້ວ.
- `reject/`: ຖ້າບໍ່ໄດ້ຮັບການຮັບຮອງເອົາ, ກະລຸນາບອກເຫດຜົນ.

ເບິ່ງ `issue/new.md`, `issue/run.md`, `issue/review.md`ສໍາລັບຂະບວນການ.

ການທົບທວນຄືນແມ່ນສຸມໃສ່ຄວາມແຕກຕ່າງທາງດ້ານພຶດຕິກໍາ, ຄວາມເຂົ້າກັນໄດ້ຂອງຮູບແບບ, ການປະຕິບັດ, ແລະໂຄງສ້າງລະຫັດລະຫວ່າງການປະຕິບັດ fkv ແລະ C ++. ຄວາມຄິດເຫັນຫນຶ່ງຕໍ່
ໄຟລ໌ເພື່ອຫຼີກເວັ້ນການຍ້າຍຫຼາຍ.
