# Esaminare i record

`issue/` è il comitato di revisione durante la migrazione:

- `new/`: voce per nuovi commenti.
- `todo/`: adottato, in attesa di sviluppo.
- `done/`: sviluppato e dotato di prove di prova, in attesa di revisione.
- `reviewed/`: archivio revisionato.
- `reject/`: Se non adottato, indicare le ragioni.

Vedi `issue/new.md`, `issue/run.md`, `issue/review.md` per il processo.

La revisione si concentra sulle differenze comportamentali, compatibilità di formato, prestazioni e struttura del codice tra le implementazioni fkv e C++. Un parere per
file per evitare spostamenti di massa.
