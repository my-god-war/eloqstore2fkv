# Repasuha ang mga rekord

`issue/` mao ang review board sa panahon sa paglalin:

- `new/`: Pagsulod para sa bag-ong mga komento.
- `todo/`: Gisagop, naghulat nga kalamboan.
- `done/`: Nahimo ug adunay pagsulay nga ebidensya, naghulat nga pagsusi.
- `reviewed/`: Gisusi ang archive.
- `reject/`: Kung wala gisagop, palihog isulti ang mga rason.

Tan-awa ang `issue/new.md`, `issue/run.md`, `issue/review.md` para sa proseso.

Ang pagrepaso nagpunting sa mga kalainan sa pamatasan, pagkaangay sa format, pasundayag, ug istruktura sa code tali sa mga pagpatuman sa fkv ug C++. Usa ka opinyon kada
mga file aron malikayan ang daghang paglihok.
