# eloqstore2fkv

Магацин за верификација на миграција и компатибилност од eloqstore до fkv.

Главното складиште на fkv останува чисто Rust и е изградено независно; ова складиште го задржува референтниот пророк за имплементација на C++, двонасочен бајт корпус,
Мигрирајте ги книгите, историските ревизорски записи и потврдете CI.

## содржина

- C++ oracle: поврзете го слојот со формат на eloqstore и генерирате страница/индекс/прелевање/манифест/
  компресира корпус.
- Двонасочен корпус: C++ пишува → Rust read, Rust write → C++ read.
- `fkv_compat`: тест за компатибилност на страната на 'рѓа, потпирајќи се на форматната гајба на складиштето fkv.
- `fkv_ledger`: скенирајте eloqstore, снимајте ја книгата за миграција, генерирајте и потврдете корпус.
- Споредба на перформансите: Споредете ги основните линии на fkv и C++ под ист обем на работа.
