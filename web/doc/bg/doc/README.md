# eloqstore2fkv

Склад за миграция и проверка на съвместимостта от eloqstore към fkv.

Основното fkv хранилище остава чисто Rust и се изгражда независимо; това хранилище запазва референтния оракул на C++, двупосочен байтов корпус,
Мигрирайте счетоводни книги, исторически записи за одит и проверете CI.

## съдържание

- C++ oracle: свържете слоя с формат на eloqstore и генерирайте page/index/overflow/manifest/
  компресиране на корпуса.
- Двупосочен корпус: C++ запис → Rust четене, Rust запис → C++ четене.
- `fkv_compat`: Тест за съвместимост от страна на Rust, разчитащ на кутията за форматиране на fkv склада.
- `fkv_ledger`: Сканирайте eloqstore, запишете книга за миграция, генерирайте и проверете корпус.
- Сравнение на производителността: Сравнете базовите линии на fkv и C++ при едно и също натоварване.
