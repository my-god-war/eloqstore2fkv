# Qeydləri nəzərdən keçirin

`issue/` miqrasiya zamanı nəzərdən keçirmə şurasıdır:

- `new/`: Yeni şərhlər üçün giriş.
- `todo/`: Qəbul edilib, işlənməni gözləyir.
- `done/`: Hazırlanıb və sınaq sübutları var, nəzərdən keçirilməsini gözləyir.
- `reviewed/`: Arxiv nəzərdən keçirildi.
- `reject/`: Əgər qəbul olunmayıbsa, lütfən, səbəbləri qeyd edin.

Proses üçün `issue/new.md`, `issue/run.md`, `issue/review.md`-ə baxın.

İcmal fkv və C++ tətbiqləri arasında davranış fərqləri, format uyğunluğu, performans və kod strukturuna diqqət yetirir. başına bir fikir
toplu hərəkətlərin qarşısını almaq üçün fayllar.
