# 2026-11-06: मुख्यपृष्ठ कार्यप्रदर्शन सारणी, सूचक विस्तार आणि पृष्ठे

आजचे अपडेट कार्यप्रदर्शन पुनरावलोकने आणि साइट लॉन्चवर लक्ष केंद्रित करते.

## मुख्यपृष्ठ कार्यप्रदर्शन तुलना

- मुख्यपृष्ठ कार्यप्रदर्शन प्राधान्यामध्ये बदलले आहे, आणि C++/Rust तुलना सारणी थेट पहिल्या स्क्रीनवर प्रदर्शित होते.
- निर्देशकांचे तीन नवीन संच जोडले आहेत: लॉजिकल बँडविड्थ, P99.9 टेल विलंब आणि अवकाशीय प्रवर्धन.
- रस्ट रनिंग तपशील जोडले: स्कॅन, फुलस्कॅन, लेखन प्रवर्धन, लेखन सिस्टम कॉलची संख्या आणि प्रति बॅच डेटा सिंक्रोनाइझेशन.
- स्पष्टपणे `write-read` मिश्रित कॅलिबर म्हणून चिन्हांकित करा आणि कार्यप्रदर्शन दस्तऐवजीकरणाशी लिंक करा.

वर्तमान समान-मशीन बेसलाइन:

| निर्देशांक | C++ | Rust | Rust / C++ |
|---|---:|---:|---:|
| Put | 16,866 kv/s | 21,377 kv/s | 1.27x |
| Get | 5,526 QPS | 7,293 QPS | 1.32x |
| Put P99 | 51.2 ms | 35.1 ms | 0.69x |
| Get P99 | 31.2 ms | 10.0 ms | 0.32x |
| Put P99.9 | 86.0 ms | 223.3 ms | 2.60x |
| Get P99.9 | 48.2 ms | 355.5 ms | 7.37x |
| शिखर RSS | 175.6 MiB | 145.5 MiB | 0.83x |
| स्टोरेज वापर | 269.0 MiB | 101.4 MiB | 0.38x |

## मूल्यांकन निर्देशक

RocksDB, LevelDB, YCSB, WiredTiger आणि इतर बेंचमार्कच्या सामान्य आउटपुटचा संदर्भ देत, मी जोडले:

- तार्किक वाचन आणि लेखन बँडविड्थ MiB/s;
- P99.9 शेपूट विलंब;
- अंतराळ प्रवर्धन, लेखन प्रवर्धन;
- प्रत्येक बॅचमध्ये सिस्टम कॉल्स आणि डेटा सिंक्रोनाइझेशनची संख्या;
- स्कॅन / फुलस्कॅन थ्रुपुट;
- सीपीयू, पेज फॉल्ट्स, कॉन्टेक्स्ट स्विचेस आणि प्रोसेस IO संसाधन साइडकारद्वारे संकलित करणे सुरू आहे.

त्याच वेळी निवृत्त झाले`gxhash_4096B_gib_s`. हा 4 KiB सिंगल ब्लॉक हॅश मायक्रोबेंचमार्क आहे जो KV इंजिन मार्गावर नाही आणि त्याला C++ काउंटरपार्ट नाही.

## अचूकता आणि अभियांत्रिकी निराकरणे

- `--rng cpp` रीड/स्कॅन ची की स्पेस फिक्स करा: 75% वाचन अलिखित की मध्ये पडू नयेत यासाठी रीड डिटेक्शन यापुढे `key_interval` ने गुणाकार केला जाणार नाही.
- macOS `openrsync` समान सामग्रीसह मॅनिफेस्टच्या चुकीच्या निर्णयामुळे निश्चित स्टँडबाय पुन्हा प्रयत्न.
- हार्डवेअर गेट समस्येचे निराकरण केले जेथे QEMU व्हर्च्युअल डिस्कचा स्थानिक SSDs म्हणून चुकीचा अंदाज लावला गेला.
