# रेकॉर्डचे पुनरावलोकन करा

`issue/` हे स्थलांतर दरम्यान पुनरावलोकन मंडळ आहे:

- `new/`: नवीन टिप्पण्यांसाठी प्रवेश.
- `todo/`: दत्तक, प्रलंबित विकास.
- `done/`: विकसित आणि चाचणी पुरावे आहेत, प्रलंबित पुनरावलोकन.
- `reviewed/`: संग्रहणाचे पुनरावलोकन केले.
- `reject/`: दत्तक नसल्यास, कृपया कारणे सांगा.

प्रक्रियेसाठी `issue/new.md`, `issue/run.md`, `issue/review.md` पहा.

पुनरावलोकन fkv आणि C++ अंमलबजावणी दरम्यान वर्तनातील फरक, स्वरूप सुसंगतता, कार्यप्रदर्शन आणि कोड संरचना यावर लक्ष केंद्रित करते. प्रति एक मत
मोठ्या प्रमाणात हालचाली टाळण्यासाठी फायली.
