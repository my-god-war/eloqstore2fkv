# कामगिरी

fkv रेपॉजिटरीमधून `perf-latest` पैकी `fkv_bench` डाउनलोड करा आणि निश्चित मशीनवर समान वर्कलोड चालवा.
आणि थ्रूपुट, लेटन्सी क्वांटाइल आणि पीक RSS ची C++ बेसलाइनशी तुलना करा.

पॅरामीटर स्त्रोत fkv शी सुसंगत आहे:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

C++ आधाररेखा ओरॅकल वातावरणाद्वारे चालवली जाते `simple_bench` आणि नंतर त्याच स्कीमानुसार आउटपुट आणि प्रकाशित केले जाते
`perf-baseline` रिलीझ मालमत्ता. तुलना परिणाम परत वेअरहाऊस दस्तऐवजावर लिहिले जातात आणि साइट थेट मार्कडाउन प्रस्तुत करते.
कोणताही JSON डेटा स्तर राखलेला नाही.
