# कामगिरी

fkv रेपॉजिटरीमधून `perf-latest` पैकी `fkv_bench` डाउनलोड करा आणि निश्चित मशीनवर समान वर्कलोड चालवा.
आणि थ्रूपुट, लेटन्सी क्वांटाइल आणि पीक RSS ची C++ बेसलाइनशी तुलना करा.

पॅरामीटर स्त्रोत fkv शी सुसंगत आहे:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

C++ आधाररेखा ओरॅकल वातावरणाद्वारे चालवली जाते `simple_bench` आणि नंतर त्याच स्कीमानुसार आउटपुट आणि प्रकाशित केले जाते
`perf-baseline` रिलीझ मालमत्ता. तुलना परिणाम परत वेअरहाऊस दस्तऐवजावर लिहिले जातात आणि साइट थेट मार्कडाउन प्रस्तुत करते.
कोणताही JSON डेटा स्तर राखलेला नाही.

48.2 ms), सिंगल बेसलाइनमध्ये मोठ्या प्रमाणात चढ-उतार होतात, कृपया तपशीलांसाठी अंतर्गत परफ रिपोर्ट पहा.

**टीप**: C++'s `write-read` म्हणजे लेखन धागा आणि वाचन धागा एकाच वेळी चालतात आणि सध्या गंजत आहे
"पूर्ण लेखन, पुन्हा उघडा आणि पुन्हा वाचा", वाचन टप्प्यात लेखन स्पर्धा नाही. त्यामुळे `write-read` चा गुणक मानला जाऊ शकत नाही
शुद्ध वाचन / शुद्ध लेखन निष्कर्ष; कठोर तुलना `scripts/perf_local.sh --symmetric` पहावी
परिणामांच्या दोन जोड्या आउटपुट आहेत: केवळ लिहिण्यासाठी आणि केवळ वाचण्यासाठी. एकल सामायिक धावपटू क्रमांक केवळ प्रतिगमनासाठी वापरले जातात
`--runs` चा मध्य वापरून ट्रेंड, रिलीझचे परीक्षण केले जाते.
