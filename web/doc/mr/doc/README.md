# eloqstore2fkv

eloqstore पासून fkv पर्यंत स्थलांतर आणि सुसंगतता पडताळणी गोदाम.

मुख्य fkv रेपॉजिटरी शुद्ध गंज राहते आणि स्वतंत्रपणे तयार केली जाते; हे भांडार C++ संदर्भ अंमलबजावणी ओरॅकल, द्विदिशात्मक बाइट कॉर्पस राखून ठेवते,
खातेवही, ऐतिहासिक लेखापरीक्षण नोंदी स्थलांतरित करा आणि CI सत्यापित करा.

## सामग्री

- C++ ओरॅकल: eloqstore फॉरमॅट लेयर लिंक करा आणि पेज/इंडेक्स/ओव्हरफ्लो/मॅनिफेस्ट/ व्युत्पन्न करा
  कॉर्पस कॉम्प्रेस करा.
- द्विदिशात्मक कॉर्पस: C++ लिहा → रस्ट रीड, रस्ट राइट → C++ रीड.
- `fkv_compat`: रस्ट-साइड सुसंगतता चाचणी, fkv वेअरहाऊसच्या फॉरमॅट क्रेटवर अवलंबून.
- `fkv_ledger`: eloqstore स्कॅन करा, मायग्रेशन लेजर रेकॉर्ड करा, कॉर्पस तयार करा आणि सत्यापित करा.
- कार्यप्रदर्शन तुलना: समान वर्कलोड अंतर्गत fkv आणि C++ बेसलाइनची तुलना करा.
