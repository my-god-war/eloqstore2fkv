# 2026-11-06: હોમ પેજ પ્રદર્શન કોષ્ટક, સૂચક વિસ્તરણ અને પૃષ્ઠો

આજનું અપડેટ પ્રદર્શન સમીક્ષાઓ અને સાઇટ લોંચ પર ધ્યાન કેન્દ્રિત કરે છે.

## હોમ પેજ પ્રદર્શન સરખામણી

- હોમપેજને પરફોર્મન્સ પ્રાધાન્યતામાં બદલવામાં આવે છે, અને C++/રસ્ટ સરખામણી કોષ્ટક સીધી પ્રથમ સ્ક્રીન પર પ્રદર્શિત થાય છે.
- સૂચકોના ત્રણ નવા સેટ ઉમેરવામાં આવ્યા છે: લોજિકલ બેન્ડવિડ્થ, P99.9 પૂંછડી વિલંબ અને અવકાશી એમ્પ્લીફિકેશન.
- રસ્ટ રનિંગ વિગતો ઉમેરી: સ્કેન, ફુલસ્કેન, રાઈટ એમ્પ્લીફિકેશન, રાઈટ સિસ્ટમ કોલની સંખ્યા અને બેચ દીઠ ડેટા સિંક્રોનાઈઝેશન.
- સ્પષ્ટપણે `write-read`ને મિશ્ર કેલિબર તરીકે ચિહ્નિત કરો અને પ્રદર્શન દસ્તાવેજીકરણ સાથે લિંક કરો.

વર્તમાન સમાન-મશીન આધારરેખા:

| અનુક્રમણિકા | C++ | Rust | Rust / C++ |
|---|---:|---:|---:|
| Put | 16,866 kv/s | 21,377 kv/s | 1.27x |
| Get | 5,526 QPS | 7,293 QPS | 1.32x |
| Put P99 | 51.2 ms | 35.1 ms | 0.69x |
| Get P99 | 31.2 ms | 10.0 ms | 0.32x |
| Put P99.9 | 86.0 ms | 223.3 ms | 2.60x |
| Get P99.9 | 48.2 ms | 355.5 ms | 7.37x |
| પીક RSS | 175.6 MiB | 145.5 MiB | 0.83x |
| સંગ્રહ વપરાશ | 269.0 MiB | 101.4 MiB | 0.38x |

## મૂલ્યાંકન સૂચકાંકો

RocksDB, LevelDB, YCSB, WiredTiger અને અન્ય બેન્ચમાર્કના સામાન્ય આઉટપુટનો સંદર્ભ આપતા, મેં ઉમેર્યું:

- લોજિકલ રીડ અને રાઈટ બેન્ડવિડ્થ MiB/s;
- P99.9 પૂંછડી વિલંબ;
- જગ્યા એમ્પ્લીફિકેશન, લેખન એમ્પ્લીફિકેશન;
- દરેક બેચમાં સિસ્ટમ કૉલ્સ અને ડેટા સિંક્રનાઇઝેશનની સંખ્યા;
- સ્કેન / ફુલસ્કેન થ્રુપુટ;
- CPU, પૃષ્ઠ ખામી, સંદર્ભ સ્વીચો અને પ્રક્રિયા IO સંસાધન સાઇડકાર દ્વારા એકત્રિત કરવાનું ચાલુ રાખે છે.

તે જ સમયે નિવૃત્ત થયા`gxhash_4096B_gib_s`. તે 4 KiB સિંગલ બ્લોક હેશ માઇક્રોબેન્ચમાર્ક છે જે KV એન્જિન પાથ પર નથી અને તેમાં C++ સમકક્ષ નથી.

## સચોટતા અને એન્જિનિયરિંગ સુધારાઓ

- `--rng cpp` રીડ/સ્કેન ની કી સ્પેસ ફિક્સ કરો: રીડ ડિટેક્શનને હવે `key_interval` વડે ગુણાકાર કરવામાં આવશે નહીં જેથી 75% રીડ અલિખિત કીમાં ન આવે.
- macOS `openrsync` સમાન સામગ્રી સાથે મેનિફેસ્ટના ગેરસમજને કારણે સ્થિર સ્ટેન્ડબાય પુનઃપ્રયાસો.
- હાર્ડવેર ગેટની સમસ્યાને ઠીક કરવામાં આવી છે જ્યાં QEMU વર્ચ્યુઅલ ડિસ્કને સ્થાનિક SSDs તરીકે ખોટી ગણવામાં આવી હતી.

## સાઇટ્સ અને પબ્લિશિંગ

- GitHub પૃષ્ઠો સક્ષમ: <https://my-god-war.github.io/eloqstore2fkv/>
- સાઇટ રૂટીંગ `/eloqstore2fkv/` સબપાથને સપોર્ટ કરે છે.
- તેના બદલે દસ્તાવેજ `raw.githubusercontent.com` થી વાંચવામાં આવે છે, અને jsDelivr પાથમાં ગુમ થયેલ `web/`ને કારણે થયેલ 404 સુધારેલ છે.
- બ્લોગ નેવિગેશન અને `bun run tran` બહુભાષી અનુવાદ સંકલિત છે; આ લેખ ચીની સ્ત્રોતમાંથી અન્ય ભાષાઓમાં આપમેળે અનુવાદિત થાય છે.

અનુગામી ચેન્જલોગ સુસંગતતા, પ્રદર્શન અને ટૂલચેન ફેરફારોને દસ્તાવેજ કરવાનું ચાલુ રાખશે.
