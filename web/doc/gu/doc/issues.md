# રેકોર્ડની સમીક્ષા કરો

`issue/` સ્થળાંતર દરમિયાન સમીક્ષા બોર્ડ છે:

- `new/`: નવી ટિપ્પણીઓ માટે પ્રવેશ.
- `todo/`: અપનાવેલ, બાકી વિકાસ.
- `done/`: વિકસિત અને પરીક્ષણ પુરાવા ધરાવે છે, સમીક્ષા બાકી છે.
- `reviewed/`: આર્કાઇવની સમીક્ષા કરી.
- `reject/`: જો અપનાવ્યું ન હોય, તો કૃપા કરીને કારણો જણાવો.

પ્રક્રિયા માટે `issue/new.md`, `issue/run.md`, `issue/review.md` જુઓ.

સમીક્ષા fkv અને C++ અમલીકરણો વચ્ચે વર્તણૂકીય તફાવતો, ફોર્મેટ સુસંગતતા, પ્રદર્શન અને કોડ માળખું પર ધ્યાન કેન્દ્રિત કરે છે. પ્રતિ એક અભિપ્રાય
જથ્થાબંધ ચાલ ટાળવા માટે ફાઇલો.
