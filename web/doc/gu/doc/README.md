# eloqstore2fkv

eloqstore થી fkv સુધી સ્થળાંતર અને સુસંગતતા ચકાસણી વેરહાઉસ.

મુખ્ય fkv રીપોઝીટરી શુદ્ધ રસ્ટ રહે છે અને સ્વતંત્ર રીતે બનેલ છે; આ ભંડાર C++ સંદર્ભ અમલીકરણ ઓરેકલ, બાયડાયરેક્શનલ બાઈટ કોર્પસ જાળવી રાખે છે,
ખાતાવહી, ઐતિહાસિક ઓડિટ રેકોર્ડ્સ સ્થાનાંતરિત કરો અને CI ની ચકાસણી કરો.

## સામગ્રી

- C++ ઓરેકલ: eloqstore ફોર્મેટ લેયરને લિંક કરો અને પેજ/ઇન્ડેક્સ/ઓવરફ્લો/મેનિફેસ્ટ/ જનરેટ કરો
  કોમ્પ્રેસ કોર્પસ.
- બાયડાયરેક્શનલ કોર્પસ: C++ લખો → રસ્ટ રીડ, રસ્ટ લખો → C++ રીડ.
- `fkv_compat`: રસ્ટ-સાઇડ સુસંગતતા પરીક્ષણ, fkv વેરહાઉસના ફોર્મેટ ક્રેટ પર આધાર રાખીને.
- `fkv_ledger`: eloqstore સ્કેન કરો, માઈગ્રેશન લેજર રેકોર્ડ કરો, કોર્પસ જનરેટ કરો અને વેરિફાઈ કરો.
- પ્રદર્શન સરખામણી: સમાન વર્કલોડ હેઠળ fkv અને C++ બેઝલાઇનની તુલના કરો.
