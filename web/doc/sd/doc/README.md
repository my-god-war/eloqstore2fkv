# eloqstore2fkv

لڏپلاڻ ۽ مطابقت جي تصديق واري گودام eloqstore کان fkv تائين.

مکيه fkv مخزن خالص مورچا رهي ٿو ۽ آزاد طور تي ٺهيل آهي. هي مخزن C++ ريفرنس پليپشن oracle، bidirectional byte corpus کي برقرار رکي ٿو،
لڏپلاڻ ليجرز، تاريخي آڊٽ رڪارڊ ۽ تصديق ڪريو CI.

## مواد

- C++ oracle: لنڪ eloqstore فارميٽ پرت ۽ صفحو/index/overflow/manifest/ ٺاهي
  جسم کي دٻائڻ.
- ٻه طرفي ڪارپس: C++ لکو → مورچا پڙهو، زنگ لکو → C++ پڙهو.
- `fkv_compat`: مورچا-پاسي مطابقت ٽيسٽ، fkv گودام جي فارميٽ ڪرٽ تي ڀروسو ڪندي.
- `fkv_ledger`: اسڪين eloqstore، رڪارڊ لڏپلاڻ ليجر، ٺاھيو ۽ تصديق ڪريو ڪورپس.
- ڪارڪردگي جو مقابلو: ساڳي ڪم لوڊ تحت fkv ۽ C++ بيس لائنن جو مقابلو ڪريو.
