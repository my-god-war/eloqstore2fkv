# ڪارڪردگي

ڊائون لوڊ ڪريو `perf-latest` جو `fkv_bench` fkv مخزن مان ۽ هڪ مقرر ٿيل مشين تي ساڳيو ڪم لوڊ ڪريو.
۽ ڀيٽ ڪريو throughput، latency quantiles، ۽ چوٽي RSS کي C++ بيس لائين.

پيٽرولر جو ذريعو fkv سان مطابقت رکي ٿو:

- `PERF_ROWS`
- `PERF_BATCH_SIZE`
- `PERF_WORKLOAD`
- `PERF_BENCH_ROOT`

C++ بيس لائين oracle ماحول `simple_bench` ذريعي هلندي آهي ۽ پوءِ ان ئي اسڪيما جي مطابق آئوٽ ڪيو ۽ شايع ڪيو ويو
`perf-baseline` اثاثو ڇڏڻ. مقابلي جا نتيجا گودام دستاويز ڏانهن واپس لکيا ويا آهن، ۽ سائيٽ سڌو سنئون مارڪ ڊائونڊ کي ڏئي ٿو.
ڪابه JSON ڊيٽا پرت برقرار نه آهي.

## موجوده نتيجا

اسڪيما 2 بيس لائين 2026-11-06T04:25Z،`github-ubuntu-latest-x86_64`، 4 KiB صفحو،
`data_append_mode=false`، `direct_io=true`. مقرر ٿيل ڪم لوڊ:
`rows/max_key=1000000`،`batch_size=100`،`write_batchs=10000`،
`read_per_part=4`،`partitions=1`،`kv_size=128`،`rng=cpp`
(`key_interval=4` / `del_ratio=4`، `test_secs=30`.

لکڻ جي 1 ملين داخلائن (10,000 بيچ) سان ملندڙ جلندڙ آهي
`io_write_at_num=48,625`، `io_data_sync_num=10,000`، اهو آهي، ڊيٽا هڪ ڀيرو هر بيچ ۾ هم وقت سازي ڪئي وئي آهي.
مورچا اضافي ميٽرڪس: اسڪين `141,166 kv/s`، مڪمل اسڪين `108,274 kv/s`، امپليڪشن لکو `2.57x`
(`proc_io_write` 329 MB / 128 MB منطقي لکندو)، `4.86` لکو سسٽم ڪالون في بيچ.
اسٽوريج جو تناسب 1M × 128B = 128 MB نامياتي ڊيٽا جي بنياد تي ڳڻيو ويو آهي؛ C++ هن ڀيري GC/compact کي متحرڪ نٿو ڪري،
ان ڪري ان ۾ تاريخ جا وڌيڪ صفحا آهن. اهو ساڳيو ڪليبر نمبر نه آهي جيئن "بقا ڊيٽا اسپيس ايمپليفڪيشن".
مورچا جي P99.9 دم جي دير اڃا تائين C++ کان وڌيڪ خراب آهي (223.3 ms بمقابله 86.0 ms، حاصل ڪريو 355.5 ms بمقابله
48.2 ms)، سنگل بيس لائين تمام گھڻي ڦيرڦار ڪري ٿي، مھرباني ڪري تفصيل لاءِ اندروني پرف رپورٽ ڏسو.

**نوٽ**: C++'s `write-read` مطلب ته لکڻ جو سلسلو ۽ پڙهڻ وارو سلسلو هڪ ئي وقت هلندو آهي، ۽ هن وقت زنگ لڳل آهي.
”مڪمل لکو، ٻيهر کوليو ۽ ٻيهر پڙهو“ پڙهڻ واري مرحلي ۾ لکڻ جو ڪو به مقابلو ناهي. تنهن ڪري `write-read` جي ضرب کي سمجهي نه ٿو سگهجي
خالص پڙهڻ / خالص لکڻ جو نتيجو؛ سخت مقابلي کي ڏسڻ گهرجي `scripts/perf_local.sh --symmetric`
نتيجن جا ٻه جوڙو ٻاھر آھن: صرف لکڻ ۽ صرف پڙھڻ. سنگل شيئر رنر نمبر صرف رجعت لاءِ استعمال ٿيندا آهن
رجحانات، رليزز کي `--runs` جي وچين استعمال ڪندي فيصلو ڪيو وڃي ٿو.
