# رڪارڊ جو جائزو وٺو

`issue/` لڏپلاڻ دوران نظرثاني بورڊ آهي:

- `new/`: نئين تبصرن لاءِ داخلا.
- `todo/`: اختيار ڪيو ويو، التوا ۾ ترقي.
- `done/`: ترقي يافته ۽ امتحاني ثبوت آهن، نظرثاني جي انتظار ۾.
- `reviewed/`: آرڪائيو جو جائزو ورتو ويو.
- `reject/`: جيڪڏهن اختيار نه ڪيو ويو، مهرباني ڪري سبب بيان ڪريو.

ڏسو `issue/new.md`، `issue/run.md`، `issue/review.md` عمل لاءِ.

نظرثاني تي ڌيان ڏئي ٿو رويي جي اختلافن، فارميٽ جي مطابقت، ڪارڪردگي، ۽ ڪوڊ جي جوڙجڪ جي وچ ۾ fkv ۽ C++ عمل درآمد. هڪ راء في
وڏيون حرڪتون کان بچڻ لاءِ فائلون.
