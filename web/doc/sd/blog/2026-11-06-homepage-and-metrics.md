# 2026-11-06: هوم پيج ڪارڪردگي جدول، اشاري جي توسيع ۽ صفحا

اڄ جي تازه ڪاري ڪارڪردگي جي جائزي ۽ سائيٽ جي لانچ تي ڌيان ڏئي ٿي.

## گھر جي صفحي جي ڪارڪردگي جو مقابلو

- هوم پيج ڪارڪردگي جي ترجيح ۾ تبديل ڪيو ويو آهي، ۽ C++/Rust مقابلي واري ٽيبل سڌو سنئون پهرين اسڪرين تي ڏيکاريل آهي.
- اشارن جا ٽي نوان سيٽ شامل ڪيا ويا آهن: منطقي بينڊوڊٿ، P99.9 tail delay، ۽ spatial amplification.
- شامل ٿيل زنگ جي هلندڙ تفصيل: اسڪين، مڪمل اسڪين، لکڻ جي واڌاري، لکڻ جي سسٽم ڪالن جو تعداد ۽ ڊيٽا هم وقت سازي في بيچ.
- واضح طور تي نشان لڳايو `write-read` کي مخلوط ڪيليبر طور ۽ ڪارڪردگي دستاويزن سان ڳنڍيو.

موجوده ساڳي مشين بيس لائين:

| انڊيڪس | C++ | Rust | Rust / C++ |
|---|---:|---:|---:|
| Put | 16,866 kv/s | 21,377 kv/s | 1.27x |
| Get | 5,526 QPS | 7,293 QPS | 1.32x |
| Put P99 | 51.2 ms | 35.1 ms | 0.69x |
| Get P99 | 31.2 ms | 10.0 ms | 0.32x |
| Put P99.9 | 86.0 ms | 223.3 ms | 2.60x |
| Get P99.9 | 48.2 ms | 355.5 ms | 7.37x |
| چوٽي آر ايس ايس | 175.6 MiB | 145.5 MiB | 0.83x |
| اسٽوريج جو استعمال | 269.0 MiB | 101.4 MiB | 0.38x |

## تشخيص جا اشارا

RocksDB، LevelDB، YCSB، WiredTiger ۽ ٻين معيارن جي عام پيداوار جي حوالي سان، مون شامل ڪيو:

- منطقي پڙهڻ ۽ لکڻ بينڊوڊٿ MiB/s؛
- P99.9 دم دير؛
- خلائي واڌارو، لکڻ جي واڌاري؛
- هر بيچ ۾ سسٽم ڪالن ۽ ڊيٽا جي هم وقت سازي جو تعداد؛
- اسڪين / مڪمل اسڪين ذريعي؛
- سي پي يو، صفحي جي غلطيون، حوالن جي سوئچز، ۽ پروسيس IO وسيلن جي سائڊ ڪار پاران گڏ ٿيڻ جاري آھي.

ساڳئي وقت رٽائرڊ `gxhash_4096B_gib_s`. اهو هڪ 4 KiB سنگل بلاڪ هيش مائڪرو بينچ مارڪ آهي جيڪو KV انجڻ جي رستي تي نه آهي ۽ نه ئي C++ هم منصب آهي.

## درستگي ۽ انجنيئرنگ fixes

- `--rng cpp` جي اهم اسپيس کي درست ڪريو پڙھڻ/اسڪين ڪريو: پڙھڻ جي سڃاڻپ کي ھاڻي `key_interval` سان ضرب نه ڪيو ويو آھي پڙھڻ جي 75٪ کان بچڻ لاءِ اڻ لکت ڪيل ڪيز ۾ اچڻ کان.
- MacOS `openrsync` ساڳئي مواد سان منشور جي غلط فيصلي جي ڪري مقرر ٿيل اسٽينڊ بائي ٻيهر ڪوششون.
- هارڊويئر گيٽ جو مسئلو حل ڪيو جتي QEMU ورچوئل ڊسڪ کي مقامي SSDs طور غلط سمجهيو ويو.
