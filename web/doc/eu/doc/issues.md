# Erregistroak berrikusi

`issue/` berrikuspen batzordea da migrazioan:

- `new/`: iruzkin berrietarako sarrera.
- `todo/`: onartua, garatzeko zain.
- `done/`: garatu eta probaren frogak ditu, berrikuspenaren zain.
- `reviewed/`: Artxiboa berrikusi da.
- `reject/`: Adoptatu ez bada, adierazi arrazoiak.

Ikusi `issue/new.md`, `issue/run.md`, `issue/review.md` prozesua ezagutzeko.

Berrikuspena fkv eta C++ inplementazioen arteko portaera desberdintasunetan, formatu bateragarritasunean, errendimenduan eta kode egituran zentratzen da. Iritzi bat bakoitzeko
fitxategiak mugimendu masiboa saihesteko.
